# 10. 추가 집단 12종

가문, 도적단, 교단, 나라, 마을 외에 12종을 더한다. 유형마다 **다른 집단이 대신할 수 없는 고유 기능**을 하나 이상 가진다. 고유 기능이 없는 집단은 만들지 않는다.

특성 표를 읽는 법은 08_group_traits.md와 같다. 구분(기본/해금), 조건, (유지), 배타.

---

## 1. 부족 (혈연)

혈연 씨족들의 연합. 나라가 생기기 전 단계이고, 혈통 점수와 가장 가까운 집단이다.

| 항목 | 내용 |
|---|---|
| 창설 | 혼인으로 이어진 가문 3개 이상 + 족장 추대(가주들 투표) |
| 수장 | 족장 |
| 결정 | 원로 회의(씨족장들) |
| 고유 기능 | **혈연 충성**: 부족원끼리는 공통 조상과의 혈통 비율만큼 충성 보정을 받는다(r 0.25면 +25). **이동**: 부족 전체가 토지를 옮길 수 있다 |
| 전환 | 정착지 3곳 + "족장 세습" 부족법 → 나라 |

## 2. 자치 도시 (영토)

## 3. 연맹 (영토)

집단들의 집단. 제국, 도시 동맹, 부족 연맹이 모두 여기에 든다.

| 항목 | 내용 |
|---|---|
| 창설 | 나라, 자치 도시, 부족 중 3개 이상이 종속 또는 동맹 서약 |
| 수장 | 맹주(또는 황제). 회원 집단의 수장 중 하나 |
| 결정 | 회원 집단 수장들의 권력 지분 투표 |
| 고유 기능 | **회원 간 중재**: 회원끼리 전쟁하려면 연맹 승인이 필요하다. **칭호**: 맹주 칭호는 회원 집단 정통성 위에 얹힌다 |
| 전환 | 맹주 집중도 70% + "제국 칭호" → 회원 나라들이 맹주 나라에 흡수 가능 |

| 헌장 | 구분 | 조건 | 효과 | 배타 |
|---|---|---|---|---|
| 공동 방위 | 기본 | | 회원이 공격받으면 전원 참전 | |
| 내전 금지 | 기본 | | 회원 간 전쟁 금지. 어기면 제명 | |
| 맹주 세습 | 기본 | | 승계 슬롯을 장자로 고정. 맹주 정통성 +10 | 맹주 선출 |
| 맹주 선출 | 기본 | | 승계 슬롯을 공개 선출로 고정. 선거인(회원 수장 일부) 매수 가능 | 맹주 세습 |
| 관세 동맹 | 기본 | | 회원 간 관세 없음 | |

| 결정 | 수장 독단 |

## 6. 봉기군 (무력, 임시)

불만이 무력이 된 임시 집단. 이기거나 지면 사라진다.

| 항목 | 내용 |
|---|---|
| 창설 | 같은 수장에게 원한 40 이상인 인물 10명 + 선동자(반란 선동 성공) |
| 수장 | 선동자 |
| 결정 | 구성원 1인 1표 |
| 고유 기능 | **요구 강제**: 승리하면 요구 슬롯의 내용이 입법 절차 없이 즉시 적용된다. **전파**: 이웃 마을의 원한 높은 인물이 매주 확률로 가담한다 |
| 결말 | 승리 → 요구 적용 후 해산, 또는 나라, 자치 도시로 전환 / 패배 → 가담자 반역자 이력, 잔당은 도적단 |

| 요구 | 구분 | 조건 | 승리 시 효과 |
|---|---|---|---|
| 세금 감면 | 기본 | | 세율 절반, 5년 |
| 특정 인물 처벌 | 기본 | | 지목한 인물(대개 관리) 처형 또는 추방 |
| 농노 해방 | 기본 | | 농노제 폐지 |
| 노예 해방 | 기본 | | 노예제 폐지 |
| 종교 자유 | 기본 | | 종교 관용 법 |
| 수장 퇴위 | 해금 | 가담자 200 | 수장 교체. 새 수장 후보를 요구에 지정 |
| 독립 | 해금 | 가담자가 한 지역 인구의 50% | 그 지역이 나라 또는 자치 도시로 독립 |

## 13. 집단 전환 지도

신분 전환이 버튼이 아니듯 집단 전환도 조건이 쌓여서 일어난다. 전환하면 기존 특성 중 새 유형에 대응하는 것이 넘어가고 나머지는 사라진다.

```
도적단 ──계약 완수──▶ 용병단 ──숙영지──▶ 영주(나라 종속 가문)
  │                     │
  │                     └──친위대──▶ 나라 수장 교체 개입
  ├──도시 정착──▶ 범죄 조직 ──합법 위장──▶ 상단
  └──통행세, 정통성──▶ 나라

봉기군 ──승리──▶ 나라 / 자치 도시
       └─패배──▶ 도적단

부족 ──족장 세습, 정착지 3──▶ 나라 ──3개 이상 연합──▶ 연맹

마을 ──도시화, 특허장──▶ 자치 도시 ──자유 도시──▶ 나라와 동격

비밀결사 ──드러남──▶ 교단        학파 ──이단 학설──▶ 교단
교단 내 파벌 ──최후통첩 거부──▶ 분파 교단

기사단 ──독립──▶ 나라
```

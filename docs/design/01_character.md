# 01. 인물

인물 하나는 아래 일곱 층으로 이루어진다.

| 층 | 유전 | 바뀌는가 | 개수 |
|---|---|---|---|
| 외형 | 유전 | 안 바뀜(나이로만 변함) | 유전자 6개 |
| 능력치 | 유전 + 환경 | 성장기에 정해지고 노화로 떨어짐 | 6개 |
| 형질 | 유전 | 안 바뀜 | 0~4개 발현 |
| 성격 | 일부 영향 | 큰 사건으로만 바뀜 | 슬롯 3개 고정 |
| 재능 | 반쯤 유전 | 안 바뀜. 6세까지 숨겨짐 | 0~2개, 18종 |
| 이력 | 안 함 | 사건과 범죄로 쌓임 | 제한 없음, 22종 |
| 기술 | 안 함 | 경험과 교육으로 오름 | 13개 수치 + 숙련 슬롯 1~5 |

## 1. 외형

화면 스프라이트와 매력 계산에 쓴다. 대립유전자 2개(부, 모 각 1개)를 가진다.

| 유전자 | 값 | 우성 규칙 |
|---|---|---|
| 피부색 | 1~5 | 두 값 평균 |
| 머리색 | 검정 / 갈색 / 금발 / 적발 | 검정 > 갈색 > 금발 > 적발 |
| 눈색 | 갈색 / 녹색 / 청색 | 갈색 > 녹색 > 청색 |
| 키 | 1~10 | 평균 + 영양 보정 |
| 얼굴형 | 6종 | 무작위 한쪽 |
| 골격 | 가냘픔 / 보통 / 단단함 | 평균 |

외형 유전자는 점수에 영향이 없다. 대신 외형이 비슷한 아이는 "닮았다"고 판정해서 사생아 비밀이 들킬 확률을 바꾼다(05_secrets.md).

## 2. 능력치

0~20. 성인 평균 10.

| 능력치 | 쓰임 |
|---|---|
| 체격 | 힘, 노동량, 근접 전투, 위압 |
| 체력 | 질병 저항, 수명, 출산 생존, 지구력 |
| 민첩 | 사냥, 은밀, 원거리 전투 |
| 지능 | 기술 습득 속도, 숙련 슬롯 수, 음모 |
| 의지 | 고문 저항, 스트레스 저항, 위협 저항 |
| 매력 | 구애, 설득, 첫인상 호감 |

**유전 공식**

```
타고난 값 = (부 + 모) / 2 + 정규분포(평균 0, 표준편차 2)
성인 값   = 타고난 값 + 성장기 보정
```

성장기 보정(0~15세 누적)

| 조건 | 체격 | 체력 | 지능 |
|---|---|---|---|
| 육류 꾸준히 섭취 | +2 | +1 | 0 |
| 곡식만 섭취 | 0 | 0 | 0 |
| 굶주림 1년 이상 | -3 | -2 | -1 |
| 교육(학문 스승) | 0 | 0 | +2 |
| 중노동 아동 | +1 | -2 | -1 |

이 보정 때문에 식량 종류가 다음 세대 능력치를 바꾼다. 육류 공급이 정치 자원이 된다.

**노화**: 45세부터 매년 체격, 체력, 민첩 중 하나가 1 떨어진다. 60세부터 지능도 떨어질 수 있다.

## 3. 형질 (유전)

형질마다 대립유전자 2개를 가진다. 우성 형질은 하나만 있어도 발현하고, 열성 형질은 둘 다 있어야 발현한다. 발현하지 않아도 보인자로 물려준다. 근친혼은 열성 형질을 자연스럽게 끌어낸다.

| 형질 | 유형 | 기본 보유율 | 효과 |
|---|---|---|---|
| 거구 | 우성 | 3% | 체격 +4, 식량 소비 +50% |
| 미모 | 우성 | 4% | 매력 +4 |
| 총명 | 열성 | 6% | 지능 +4, 기술 습득 +30% |
| 강골 | 열성 | 6% | 체력 +4, 질병 저항 |
| 장수 | 열성 | 5% | 노화 시작 +15년 |
| 다산 | 우성 | 5% | 임신 확률 +50%, 쌍둥이 확률 증가 |
| 예민한 감각 | 열성 | 5% | 비밀 인지 +25%, 사냥 +20% |
| 왜소 | 열성 | 6% | 체격 -4 |
| 추형 | 열성 | 4% | 매력 -4 |
| 우둔 | 열성 | 5% | 지능 -4 |
| 병약 | 열성 | 6% | 체력 -4 |
| 불임 경향 | 열성 | 4% | 임신 확률 -70% |
| 출혈병 | 열성, 부계 X연관 | 2% | 부상 사망률 3배, 남성에게 주로 발현 |
| 광기 | 열성 | 3% | 성인 이후 매년 2% 확률로 발병. 성격 무작위 교체 |

"기본 보유율"은 게임 시작 인구에서 대립유전자 하나를 가진 비율이다.

형질은 외부에서 바로 보이지 않는다. 발현 형질은 만나면 알 수 있고, 보인자 여부는 부모와 형제를 보고 추정하거나 의술 기술로 진단한다.

## 4. 성격

반대 쌍 12개에서 **슬롯 3개**를 채운다. 같은 쌍의 양쪽을 동시에 가질 수 없다.

| 쌍 | 효과 요약 |
|---|---|
| 용감 / 겁많음 | 전투 참여, 위협 저항 |
| 탐욕 / 관대 | 뇌물 수락, 분배 규율 반응 |
| 야심 / 만족 | 비밀을 무기로 쓰는지, 반란 성향 |
| 정직 / 기만 | 거짓말, 비밀 발설 방식 |
| 잔인 / 자비 | 포로 처우, 처벌 반응 |
| 독실 / 냉소 | 교리 반응, 개종 저항 |
| 근면 / 게으름 | 노동량 ±25% |
| 사교 / 내향 | 소문 전파 속도, 대화 효과 |
| 충직 / 변덕 | 충성 감소 속도 |
| 성급 / 인내 | 계획 음모 성공률, 협상 |
| 색욕 / 절제 | 구애 빈도, 불륜 확률 |
| 복수심 / 관용 | 원한 지속 기간 |

**결정 시점**

- 5세: 1번 슬롯. 부모 성격 중 하나를 40% 확률로 따라간다.
- 12세: 2번 슬롯. 성장 환경 사건이 정한다(굶주림 → 탐욕, 학대 → 잔인 또는 겁많음 등).
- 16세: 3번 슬롯. 무작위 또는 교육자의 성격.

**바뀌는 경우**: 큰 사건(가족 몰살, 개종 체험, 고문 생존 등)은 슬롯 하나를 교체한다. 평생 2회까지.

## 5. 재능

기술 하나 이상에 대한 타고난 적성. **슬롯 0~2개**. 재능마다 등급이 둘 있다. **재능**과 **천재**다.

### 유전과 발견

- 부모가 가진 재능을 각각 30% 확률로 물려받는다. 부모 둘 다 같은 재능이면 60%이고, 이때 3분의 1은 천재로 나온다.
- 물려받은 것과 별개로 10% 확률로 새 재능이 무작위로 생긴다.
- 슬롯 2개가 넘치면 등급이 높은 것, 같으면 먼저 정해진 것을 남긴다.
- **재능은 6세까지 숨겨져 있다.** 6세 이후 관련 일을 하거나 교육을 받으면 매주 5% 확률로 드러난다. 숨어 있어도 효과는 작동한다. 그래서 농사꾼 집 아이가 화술 천재인 줄 모르고 자랄 수 있다. 다른 사람이 먼저 알아채면 그 사람에게 쓸모 있는 정보가 된다.

### 공통 효과

| 등급 | 관련 기술 습득 | 관련 기술 최대치 | 판정 보정 |
|---|---|---|---|
| 재능 | 2배 | 120 | +10 |
| 천재 | 3배 | 150 | +20 |

### 재능이 다른 시스템과 맞물리는 지점

- 숨은 재능 때문에 교육 선택이 도박이 된다. 어떤 아이에게 스승을 붙일지 정하는 게 투자다.
- 재능은 유전되니 결혼 상대의 재능이 혈통의 값을 정한다. 천재 혈통은 정략혼 시장에서 비싸다.
- 그림자, 눈치, 강철 정신은 비밀 시스템과 바로 연결된다. 첩보 가문을 만드는 길이 된다.
- 통솔, 행정은 집단 슬롯을 늘린다. 같은 도적단이라도 두목이 누구냐에 따라 규율 수가 달라진다.

## 6. 기술

0~100. 13개.

| 기술 | 쓰임 |
|---|---|
| 농사 | 곡식 수확량, 개간 속도 |
| 채집 | 목재, 석재, 광석, 섬유 획득량 |
| 사냥 | 육류 획득량 |
| 제작 | 도구, 의류, 무기, 갑옷 품질과 속도 |
| 전투 | 개인 전투력 |
| 지휘 | 부대 전투력, 도적단 규율 유지 |
| 관리 | 세금 효율, 법 슬롯 확장, 창고 손실 감소 |
| 교역 | 매매 가격, 계약 조건 |
| 언변 | 설득, 구애, 선동 |
| 학문 | 글 읽기(30 이상), 교육, 경전 편찬 |
| 신학 | 교리 제정, 개종, 교단 지위 |
| 은밀 | 비밀 캐기, 암살, 위장 |
| 의술 | 치료, 출산 보조, 형질 진단, 독약 |

**습득**: 해당 일을 하면 주마다 오른다. `상승량 = 기본 1 × (지능 / 10) × 재능 배수 × 스승 배수(최대 2)`. 높을수록 느려진다(50 이상 절반, 80 이상 4분의 1). **전투 기술**은 훈련으로 이 값의 0.3배만 오르고, 실전 1회를 살아남으면 +2다. 60까지 약 5년 걸린다.

**숙련 슬롯**: 기술이 50, 80에 도달하면 해당 기술의 숙련 특성 하나를 고를 수 있다. 숙련 슬롯 수는 지능으로 정한다.

| 지능 | 0~7 | 8~11 | 12~15 | 16~19 | 20+ |
|---|---|---|---|---|---|
| 숙련 슬롯 | 1 | 2 | 3 | 4 | 5 |

숙련 특성 예시: 대장장이(제작 금속 효율 +50%), 사냥꾼(사냥 +50%), 웅변가(설득 +20), 첩보원(비밀 캐기 +25%), 농학자(수확 +30%), 교관(가르치는 기술 습득 2배) 등. 기술마다 2개씩 총 26개로 시작한다.

## 7. 상태

| 상태 | 범위 | 내용 |
|---|---|---|
| 건강 | 0~100 | 0이면 사망. 부상, 질병, 굶주림으로 줄어든다 |
| 허기 | 0~4주 | 식량을 못 먹은 주 수. 2주부터 건강 감소 |
| 추위 | 겨울에 의류 없으면 주마다 건강 -5 |
| 스트레스 | 0~100 | 성격에 어긋나는 명령을 수행하면 오른다. 100이면 정신붕괴(도주, 자살, 광기 발병 중 하나) |
| 나이 | | 0~15 아동(노동 50%), 16~44 성인, 45+ 노년 |

## 8. 번식

번식은 **관계 횟수**로 상한을 건다. 올인 루트의 강도를 이 상한으로 조절한다. 수치는 경제 시뮬레이터로 맞췄다(15_house_tax_inheritance.md, tools/econ_sim).

| 항목 | 값 |
|---|---|
| 관계 횟수 | 인물마다 주당 최대 1회. 색욕 성격 2회. 45세 이후 체력 12 미만이면 격주 1회 |
| 1회당 임신 확률 | 3%. 체력, 다산(+50%), 불임 경향(-70%)으로 보정. 굶주리면 (식량 충족률)² 배 |
| 부부 동거 | 매주 27% 확률로 관계. 실질 임신 확률 주당 약 0.8%, 연 약 32% |
| 임신 가능 | 여성 16~45세 |
| 출산 후 | 여성은 1년 동안 임신 불가(수유) |
| 출산 사망률 | 기본 2%. 체력 15 이상 절반, 의술 40 이상 산파가 있으면 절반 |
| 영아 사망률 | 기본 15%. 굶주리면 늘어난다 |
| 혈통 비율 | 부모 평균(07_score_succession.md) |

**연간 자녀 상한 (기대값)**

| 경우 | 연간 자녀 | 평생 |
|---|---|---|
| 일부일처 부부 | 약 0.24 (수유 기간 포함) | 출생 약 6~7명 |
| 여성 1인의 최대 | 약 0.45 (매주 관계할 때) | |
| 남성 1인, 상대 여럿, 매주 관계 | 약 1.4 | 40년 약 58명 |
| 남성 1인, 색욕, 상대 여럿, 주 2회 | 약 2.9 | 40년 약 115명 |

남성 중심 독점 루트는 일부일처보다 6~12배 빠르다. 대가는 11_routes.md의 반격 장치가 맡는다. 여성 인물은 본인 출산 상한이 낮다. 그래서 여성 루트는 자녀와 손자 대의 확산, 즉 **수장 가문 범위** 특권으로 설계한다(11_routes.md).

**혼인 전망**: 가난한 남성은 혼인을 미룬다. 굶는 가구의 남성은 해마다 혼인 확률이 10%, 땅도 소작도 없으면 20%, 그 밖은 60%다. 계산에서 이 규칙이 없으면 땅이 찬 뒤 굶주림이 50%까지 치솟았다.

**양육 비용**: 아동 1명은 식량 0.5/주를 15년 동안 쓴다. 자녀 50명이면 식량 25/주다. 성인 25명이 일해야 대는 양이다.

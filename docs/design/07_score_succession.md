# 07. 점수와 승계

## 1. 혈통 비율

플레이어의 **시조**는 게임 시작 캐릭터다. 모든 인물은 시조 혈통 비율 r을 가진다.

```
시조 본인       r = 1
그 외 인물      r = (아버지 r + 어머니 r) / 2
```

근친혼으로 부모 둘 다 혈통을 가지면 r이 높게 유지된다. 이 구조 때문에 근친혼은 점수 측면에서 이득이고 형질 측면에서 위험하다.

**실제 혈통 기준**: 사생아, 혈통 위조가 있어도 점수는 실제 생물학적 부모로 계산한다. 족보상 혈통과 실제 혈통이 다를 수 있다.

## 2. 점수

```
혈통 점수 = Σ (살아 있는 모든 인물의 r) × 100
가문 점수 = 플레이어 가문 소속 생존 인원 × 10
총점     = 혈통 점수 + 가문 점수
```

| 예시 | 혈통 점수 |
|---|---|
| 자식 4명 (r=0.5) | 200 |
| 손자 16명 (r=0.25) | 400 |
| 증손자 64명 (r=0.125) | 800 |

세대가 내려가도 인원이 4배씩 늘면 점수가 2배씩 오른다. 반대로 자식을 2명씩만 낳으면 점수는 그대로다. 다산과 생존이 점수의 핵심이다.

가문 점수는 성(姓)을 이은 사람만 센다. 혈통 점수는 성과 무관하다. 귀족은 가문 점수와 정통성을 지키고, 평민은 혈통 점수를 넓게 퍼뜨리는 쪽으로 전략이 갈린다.

## 3. 플레이어 승계

플레이어 캐릭터가 죽으면 아래 순서로 다음 캐릭터를 정한다.

1. 플레이어 가문의 법적 상속자(가문 가훈과 소속 나라 상속법 기준)
2. 상속자가 없으면 플레이어가 생전에 지정한 후계자. r > 0 이어야 한다
3. 그것도 없으면 r이 가장 높은 생존 성인. 이때 플레이어는 그 인물의 가문으로 옮겨 간다

플레이어 캐릭터만 이어받고, 직위와 재산은 법대로 따로 나뉜다. 분할 상속 법 아래에서는 플레이어가 영지를 잃고 형제가 영주가 될 수도 있다.

## 4. 게임 종료

- r > 0인 인물이 모두 죽으면 종료.
- 정해진 연수(기본 300년)가 지나면 종료하고 최종 점수를 기록한다.
- 기록 화면에 세대별 혈통 분포 지도를 보여 준다.

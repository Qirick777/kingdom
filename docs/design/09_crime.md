# 09. 범죄

## 1. 범죄의 정의

범죄는 **행위**와 **규범**의 조합이다. 같은 행위라도 어느 집단의 규범 아래에 있느냐에 따라 범죄가 되기도 하고 안 되기도 한다.

| 판단 기준 | 예 |
|---|---|
| 나라 법 | "간통죄" 법이 있으면 불륜은 범죄. 없으면 범죄는 아니고 수치스러운 일 |
| 교단 교리 | "매춘 금지" 교리 아래 신도의 매춘은 교단 범죄. 나라가 공창을 허용해도 교단은 처벌한다 |
| 도적단 규율 | 단원끼리 훔치면 규율 위반. 바깥에서 훔치는 건 일이다 |
| 가문 가훈 | 가문 비밀을 발설하면 가문 범죄 |

행위가 어느 규범에서도 범죄가 아니어도 **사회적 수치**가 남는 경우가 있다(불륜, 매춘). 이때는 처벌이 없고 비밀의 무게만 남는다.

## 2. 범죄 목록 20개

| 범죄 | 실행 판정 | 기본 목격률 | 남는 증거 | 이득 | 기본 형벌 |
|---|---|---|---|---|---|
| 도둑질 | 은밀 + 민첩 | 15% | 장물 | 품목 | 배상 + 태형 |
| 소매치기 | 은밀 + 민첩 | 20% | 장물 | 은화 소량 | 배상 + 태형 |
| 강도 | 전투 + 체격 | 100%(피해자) | 피해자 증언 | 품목, 은화 | 투옥 또는 신체형 |
| 사기 | 언변 + 지능 | 피해자가 나중에 알아챔 30% | 문서 | 은화 | 배상 + 낙인 |
| 횡령 | 관리 + 은밀 | 장부 감사 시 발견 | 장부(문서) | 맡은 재산 | 배상 + 해고 + 투옥 |
| 밀수 | 교역 + 은밀 | 10% | 물품 | 관세 회피 | 몰수 |
| 장물 거래 | 교역 | 10% | 물품 | 은화 | 벌금 |
| 뇌물 수수 | 없음 | 5% | 증언 | 은화 | 관직 박탈 |
| 폭행 | 전투 + 체격 | 50% | 피해자 증언, 부상 | 위압, 원한 해소 | 벌금 또는 태형 |
| 살인 | 전투 또는 은밀 | 25% | 시체, 흉기 | 대상 제거 | 처형 또는 노예화 |
| 독살 | 의술 + 은밀 | 5% | 독약 | 대상 제거. 병사로 위장 | 처형 |
| 납치 | 전투 + 은밀 | 30% | 피해자 | 인질, 몸값, 혼인 | 노예화 또는 처형 |
| 방화 | 은밀 | 20% | 없음 | 시설, 창고 파괴 | 처형 |
| 불륜 | 매혹 판정(구애) | 주당 3% | 증언, 아이 | 연인, 혈통 확산 | 간통죄 법에 따름 |
| 매춘 | 매력 | 공개 행위. 범죄일 때만 문제 | 증언 | 은화, 식량 | 매춘 금지법에 따름 |
| 매춘 알선 | 강압 명령 또는 계약 | 20% | 증언 | 은화 | 벌금 + 투옥 |
| 근친 | 없음 | 혼인이면 100%, 비밀 관계면 주당 3% | 아이 | 혈통 비율 유지 | 교리에 따름 |
| 위조 | 학문 + 은밀 | 사용 시 감정 판정 | 위조 문서 | 문서 효과(족보, 계약, 소유권) | 낙인 + 투옥 |
| 탈주 | 은밀 + 민첩 | 주인 감시 수준 | 없음 | 자유 | 원래 주인에게 반환 + 태형 |
| 반역 | 음모 가담 | 가담자 수에 비례 | 가담자 증언, 문서 | 권력 교체 | 처형 + 연좌 |

**목격률 보정**

```
최종 목격률 = 기본 목격률
            × 장소 보정 (외딴곳 0.3, 마을 1, 읍 1.5, 도시 2)
            × 시간 보정 (밤 0.5)
            × (1 - 실행자 은밀 / 200)
            × 그림자 재능 (재능 0.6, 천재 0.4)
            × 치안대 법 (1.3)
```

## 3. 범죄 처리 흐름

```
실행 판정 ─┬─ 실패 ─▶ 현장에서 들킴 (목격률 100%)
           └─ 성공 ─▶ 목격 판정 ─┬─ 목격자 없음 ─▶ 이력(비밀) 생성. 증거는 남음
                                  └─ 목격자 있음 ─▶ 비밀 생성. 목격자가 증언 증거 보유
                                                       │
                              목격자의 선택(05_secrets.md 4절)
                                                       │
                               고발 ─▶ 재판 ─▶ 형벌 ─▶ 이력 공개
```

**수사**: 피해자나 관할 수장은 범인을 모를 때 수사를 맡길 수 있다. 수사관은 매주 `은밀 + 지능` 판정으로 증거를 하나씩 찾는다. 증거(장물, 흉기, 독약, 문서)는 시간이 지나면 사라진다. 장물은 팔리면 거래 상대에게 넘어가고, 그 상대도 수사 대상이 된다.

## 4. 재판

관할은 범죄가 일어난 토지의 소유자 또는 점유자다. 교단 범죄는 교단이, 도적단 내부 범죄는 두목이 다룬다.

```
유죄 점수 = 증거 강도 + 판관의 피고 원한 / 2 - 피고 권력 / 5 - 뇌물 효과 + 주사위(-20~20)
유죄 점수 ≥ 30 이면 유죄
```

| 증거 | 강도 |
|---|---|
| 소문 | 10 |
| 증언 1명 | 25. 증인이 노예, 전과자면 절반 |
| 증언 2명 이상 | 40 |
| 물증(장물, 흉기) | 35 |
| 문서 | 50 |
| 자백(고문 포함) | 60. 고문으로 받은 자백은 "결투 재판" 법 아래에서 무효 주장 가능 |

판관이 피고와 같은 가문이거나 피고에게 빚이 있으면 판결을 비틀 수 있다. 그 자체가 판관의 비밀이 된다.

## 5. 형벌

나라 법이 고를 수 있는 형벌을 정한다. 기본으로 모두 쓸 수 있고, "성문법"이 있으면 범죄별로 고정된다.

| 형벌 | 효과 |
|---|---|
| 벌금 | 은화 또는 품목 |
| 배상 | 피해자에게 지급. 피해자 원한 -30 |
| 태형 | 건강 -30. 두려움 +, 원한 + |
| 낙인 | 이력 영구 공개. 외형에 표시. 매력 -2 |
| 신체형 | 손: 제작, 전투 -50. 혀: 언변 판정 불가. 영구 |
| 투옥 | 기간 동안 행동 불가. 감옥 시설 필요 |
| 노예화 | 관할 수장의 노예. 노예제 법 필요 |
| 추방 | 관할 토지 출입 금지. 들어오면 처형 |
| 처형 | 사망. 가문 원한 +50 |
| 재산 몰수 | 재산 몰수 법 필요 |
| 파문 | 교단 형벌 |
| 연좌 | 연좌제 법 필요. 가문원에게 같은 형벌 한 단계 경감 적용 |

형벌을 집행하면 목격한 주민들의 두려움이 오르고, 피고 가문의 원한이 오른다. 너무 가벼우면 피해자 가문이 사적 복수에 나선다.

## 6. 불륜과 혈통

### 생부 결정

임신이 되면 그 주에 관계한 상대 중 하나가 생부가 된다. 상대마다 관계 빈도로 확률을 나눈다. 부부가 함께 사는 경우 배우자 비중이 기본 3, 연인 비중이 기본 1이다. 남편이 전쟁이나 여행으로 떠나 있으면 배우자 비중은 0이다.

### 발각되지 않으면

- 아이는 **법적 아버지(어머니의 남편) 가문의 자식**으로 태어난다. 성, 소속, 상속권 모두 그 가문을 따른다.
- 혈통 비율(점수)은 **생부 기준**으로 계산한다(07_score_succession.md).
- 그래서 불륜은 다른 가문의 상속 라인에 내 피를 심는 전략이 된다. 그 아이가 영주를 이으면 그 영지의 미래 후손이 모두 내 혈통 점수에 들어간다.

### 아는 사람

| 인물 | 아는 정도 |
|---|---|
| 어머니 | 생부 후보를 안다. 후보가 하나뿐이면 확신 |
| 생부 | 관계 사실을 알지만 자기 아이인지는 의심만 한다(확률 표시) |
| 목격자(하인 등) | 불륜 관계만 안다. 아이와 연결은 추론 |
| 법적 아버지 | 아래 의심 지표가 쌓이면 의심 |

### 의심 지표

법적 아버지와 주변 사람은 아래 지표가 쌓일수록 의심한다. 의심 점수가 50을 넘으면 "사생아 소문"이 생기고 100을 넘으면 그 사람은 확신한다.

| 지표 | 의심 점수 |
|---|---|
| 남편이 집을 비운 기간에 임신 | +60 |
| 불륜 소문을 들음 | +30 |
| 아이 외형이 생부를 닮음(외형 유전자 3개 이상 일치) | +20 |
| 아이 외형이 법적 부모 둘 다와 다름 | +15 |
| 유전상 불가능한 조합(예: 청색 눈 부모에게서 갈색 눈) | +100. 증거 강도 "문서"급 |
| 예민한 감각 형질 또는 눈치 재능 | 의심 점수 2배 |

유전 시스템이 있어서 불륜이 몇 세대 뒤에 드러날 수 있다. 할아버지 대의 비밀이 손자의 상속을 무너뜨린다.

### 발각되면

법적 아버지는 성격에 따라 반응한다.

| 성격 | 반응 |
|---|---|
| 복수심, 잔인 | 생부 살해 시도, 아내 처벌 |
| 정직 | 공개 고발. 간통죄가 있으면 재판 |
| 야심 | 침묵하고 생부를 협박 |
| 관용, 만족 | 아이를 그대로 키움. 아내 호감만 하락 |
| 기만 | 숨기고 아이를 상속에서 은밀히 밀어냄 |

아이의 상속권은 법적 아버지가 부인하거나 재판에서 사생아로 판정될 때 박탈된다. 생부가 아이를 인지하면 생부 가문의 사생아가 된다.

## 7. 매춘

| 항목 | 내용 |
|---|---|
| 수입 | 주당 은화 = 매력 / 4 + 지역 인구 보정. 읍과 도시에서 높음 |
| 임신 | 일반 확률. 생부는 그 주 고객 중 무작위. 후보가 많으면 아무도 확신하지 못함 |
| 질병 | 주당 1% 확률로 성병. 건강 감소, 일정 확률로 불임 경향 획득 |
| 법적 지위 | 공창 법: 합법, 세금. 매춘 금지법: 범죄. 둘 다 없음: 합법이지만 수치 |
| 고객 | 기혼 고객은 불륜 비밀을 얻음. 매춘부가 그 비밀을 아는 사람이 됨 |
| 알선 | 하인, 노예에게 강압 명령(강도 45)으로 시키거나 계약으로 고용. 알선자가 수입 일부를 가짐 |

매춘부는 고객의 비밀을 많이 아는 인물이 된다. 정보 거래의 중심이 될 수 있고, 그만큼 제거 대상도 된다.

## 8. 범죄가 맞물리는 지점

| 범죄 | 연결되는 시스템 |
|---|---|
| 도둑질, 강도 | 경제(품목 이동), 장물 시장 규율, 치안대 법 |
| 횡령 | 외주 계약의 위험. 관리 기술이 낮은 주인은 감사를 못 한다 |
| 살인, 독살 | 상속 순위 조작. 의술 재능. 가문 원한 |
| 불륜 | 혈통 점수, 상속, 외형 유전, 의심 지표 |
| 매춘 | 비밀 수집, 교리와 법의 충돌, 생부 불명 인구 |
| 위조 | 족보, 소유권, 계약. 학문 기술의 어두운 쓰임 |
| 반역 | 입법, 권력 집중도, 연좌제 |
| 탈주 | 노예제, 감시 비용, 사냥 본능 재능 |

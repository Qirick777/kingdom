# 03. 상호작용

## 1. 관계 수치

인물 A는 인물 B마다 아래 값을 가진다. 방향이 있다(A→B와 B→A는 다르다).

| 수치 | 범위 | 뜻 | 시간에 따른 변화 |
|---|---|---|---|
| 호감 | -100~100 | 좋아하는가 | 주마다 0으로 1씩 돌아감 |
| 신뢰 | 0~100 | 믿고 말하는가. 비밀 공유와 계약에 쓴다 | 배신당하면 0, 천천히 회복 |
| 두려움 | 0~100 | 겁내는가 | 위협이 멈추면 주마다 2씩 감소 |
| 원한 | 0~100 | 복수하려 하는가 | 관용 성격은 빨리, 복수심 성격은 거의 안 줄어듦 |
| 빚 | 정수 | 받은 은혜 횟수. 갚을 의무를 느끼는가 | 한 번 갚으면 1 감소 |

인물은 소속 집단마다 **충성**(0~100)을 따로 가진다(04_groups.md).

**첫인상**: 처음 만나면 `호감 = (상대 매력 - 10) × 2 + 같은 종교 +10 + 같은 집단 +10 + 성격 궁합`.

**성격 궁합**: 같은 성격 하나당 +5, 반대 성격 하나당 -10.

## 2. 판정 공식

모든 상호작용은 같은 공식을 쓴다.

```
성공 점수 = 행동자 능력 + 관계 보정 + 성격 보정 + 권력차 보정 - 요구 크기 + 주사위(-20~20)
성공 점수 ≥ 0 이면 성공
```

| 항목 | 계산 |
|---|---|
| 행동자 능력 | 행동마다 지정된 기술 / 2 + 지정된 능력치 |
| 관계 보정 | 행동마다 지정된 관계 수치 / 4 |
| 성격 보정 | 대상 성격이 그 행동에 약하면 +15, 강하면 -15 |
| 권력차 보정 | (행동자 권력 - 대상 권력) / 10. 최대 ±20 |
| 요구 크기 | 행동마다 고정값 또는 거래액 기준 |

**권력** = 직할 인원 수 + 병력 × 3 + 재산(은화 환산) / 10 + 관직 점수. 집단 지위가 높을수록 커진다.

## 4. 명령 강도

강압 명령의 요구 크기.

| 명령 | 강도 |
|---|---|
| 일상 노동 | 5 |
| 위험한 노동(광산) | 20 |
| 전투 참여 | 25 |
| 같은 신분 사람을 해치기 | 35 |
| 가족이나 동족을 해치기 | 50 |
| 자신의 교리에 어긋나는 일 | 40 |
| 자살에 가까운 임무 | 60 |

명령이 성격에 어긋나면(예: 자비 성격에게 처형 명령) 성공해도 스트레스 +20.

## 5. NPC의 행동 선택

NPC는 매주 한 번 아래 순서로 행동을 고른다.

1. **긴급 필요**: 허기 2주 이상, 추위, 생명 위협이 있으면 그것부터 해결한다.
2. **의무**: 소속 집단의 명령, 계약 이행.
3. **목표**: 성격으로 정해진 장기 목표 하나를 추구한다. 야심 → 지위 상승, 탐욕 → 재산, 색욕 → 연인, 복수심 → 원한 대상 제거, 독실 → 신앙 영향력, 만족 → 가족 유지.
4. **기회**: 위 셋이 없으면 주변 인물 중 관계 수치가 극단인 인물에게 상호작용한다.

플레이어 외주 명령은 2번(의무)에 들어간다. 충성이 낮으면 3번이 2번을 앞지른다.

# 06. 토지

## 1. 구조

토지는 집단이 아니다. 구성원이 없고 주인이 있다.

| 항목 | 내용 |
|---|---|
| 소유자 | 법적 주인(인물 또는 집단). 문서로 증명 |
| 점유자 | 실제로 차지한 인물 또는 집단. 소유자와 다를 수 있다 |
| 지형 | 평야, 숲, 구릉, 산, 늪, 강변 중 하나 |
| 개간 단계 | 황무지 → 경작지 → 정착지 → 읍 → 도시 |
| 특성 슬롯 | 개간 단계로 정해진다 |
| 시설 | 지어진 건물 목록 |
| 주민 | 거주 인물 |

## 2. 지형

| 지형 | 기본 산출 | 개간 난이도 |
|---|---|---|
| 평야 | 곡식 1.5배 | 1 |
| 숲 | 목재 2배, 사냥 1.5배, 섬유 1배 | 2 |
| 구릉 | 석재 1.5배, 곡식 0.8배 | 2 |
| 산 | 광석 가능, 석재 2배, 곡식 불가 | 3 |
| 늪 | 섬유 1.5배, 질병 위험 | 3 |
| 강변 | 곡식 1.3배, 교역 보정, 어로 가능 | 1 |
| 해안 | 어로 가능, 곡식 0.8배, 교역로 후보 | 1 |
| 암석지대 | 석재 2배, 곡식 0.5배 | 3 |
| 바다, 호수 | 통행 불가. 인접 셀에 어로 제공 | 개간 불가 |

지형 배치 규칙은 13_world_generation.md에 있다. 기온 0.25 미만 셀은 "한랭" 보정(곡식 -30%, 겨울 의류 필요 2배)을 받는다.

광석은 산 지형 중 "광맥" 특성이 있는 곳에서만 나온다.

## 3. 필지와 개간

셀 하나는 필지 64개(8×8 타일씩)로 나뉜다. 소유, 경작, 청구는 필지 단위다(14_property_and_class.md).

**필지 개간**: 필지 1개 = 4 인·주 × 지형 난이도. 하급 도구 필요. 숲 필지를 개간하면 목재 30.

| 지형 | 경작 가능 필지 비율 |
|---|---|
| 평야, 강변 | 90% |
| 해안 | 70% |
| 숲 | 개간하면 90% |
| 구릉 | 60% |
| 늪 | 배수 개간(난이도 3) 뒤 70% |
| 암석지대 | 30% |
| 산 | 0% |

**셀의 개간 단계**는 필지와 시설로 자동 판정한다.

| 단계 | 조건 | 특성 슬롯 |
|---|---|---|
| 황무지 | 경작지 필지 0 | 0 |
| 경작지 | 경작지 필지 8개 이상 | 1 |
| 정착지 | 경작지 필지 20개 + 가옥 5채 | 2 |
| 읍 | 가옥 20채 + 석조 시설 3개(창고, 대장간, 사당 등) + 교역로 | 3 |
| 도시 | 가옥 60채 + 석조 시설 8개 + 성벽(석재 300) | 4 |

**수용 인구**는 고정값이 없다. 셀의 식량 생산과 반입량이 정한다. 주거 수용(가옥 수)을 넘으면 질병 확률과 불만이 오른다.

## 4. 토지 특성

| 특성 | 조건 | 효과 |
|---|---|---|
| 비옥함 | 평야, 강변 | 곡식 +30% |
| 광맥 | 산 (발견 필요: 채집 50) | 광석 채집 가능 |
| 요새 | 석재 100 투입 | 방어 2배 |
| 교역로 | 강변 또는 인접 읍 2곳 | 교역 판정 +10, 도적 출몰 증가 |
| 성지 | 교단이 성지 선포 | 교리 슬롯 +1 (해당 교단), 순례자 유입 |
| 사냥터 | 숲 | 육류 +30%, 귀족 연회 가능 |
| 은신처 | 숲, 산, 늪 | 도적단 발각 확률 -50% |
| 관개 | 강변 + 노동 100 | 곡식 +50%, 흉년 영향 절반 |

## 6. 소유와 점유의 차이

장부상 영주의 땅이라도 도적이 점유하면 생산물은 도적에게 간다. 소유자는 아래 중 하나를 고른다.

- 토벌: 병력 소모
- 협상: 도적을 소작인이나 봉신으로 인정
- 방치: 문서상 소유권만 유지. 10년 방치하면 점유자가 소유권을 주장할 수 있다

# 00. 개요

## 한 줄 정의

명령과 외주로 사람을 움직여 가문을 키우고, 세상 인구에 내 피를 가장 많이 남기는 2.5D 왕조 시뮬레이션.

## 설계 원칙

1. **모든 결과물은 세 곳 이상에 쓰인다.** 쓸모가 하나뿐인 자원, 포로, 비밀은 만들지 않는다.
2. **모든 이득은 다음 문제를 만든다.** 성공이 새 필요를 낳아 플레이어를 다음 행동으로 민다.
3. **NPC와 플레이어는 같은 규칙을 쓴다.** 플레이어 전용 행동은 없다.
4. **신분은 고르지 않는다.** 가진 것과 지배하는 관계가 신분을 정한다.
5. **모든 관계는 공개와 비밀 중 하나다.** 숨긴 관계가 곧 비밀이다.

## 플레이 조작

- 직접 조작 없음. 인물이나 집단을 클릭해 명령 메뉴를 연다.
- 명령은 **직접 수행**과 **외주(위임)** 두 가지다.
  - 직접 수행: 플레이어 캐릭터가 시간을 들여 한다. 다른 일을 못 한다.
  - 외주: 하인, 노예, 고용인, 부하, 봉신에게 맡긴다. 결과는 맡은 사람의 기술과 충성에 달린다.
- 화면은 아이소메트릭 2.5D. 인물이 실제로 걸어가 일하는 모습을 보여 주지만 조작 대상은 아니다.

## 시작 조건

플레이어는 시작 신분을 고른다. 고른 뒤에는 시스템이 신분을 정한다.

| 시작 | 가진 것 |
|---|---|
| 떠돌이 | 몸, 하급 도구 1, 의류 1 |
| 소작농 | 가족 3~5명, 소작 계약, 곡식 소량 |
| 도적 두목 | 부하 5명, 하급 무기, 은신처 |
| 소지주 | 토지 1, 소작농 2가구, 하인 1 |
| 하급 사제 | 교단 소속, 마을 신도 소수, 글 읽기 |
| 영주 | 장원 1, 병사 10, 봉신 의무 |

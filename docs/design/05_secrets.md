# 05. 비밀

## 1. 비밀의 구조

| 항목 | 내용 |
|---|---|
| 주인 | 비밀을 숨기려는 인물 또는 집단 |
| 종류 | 아래 표 |
| 무게 | 1~100. 공개될 때 주인이 잃는 크기 |
| 증거 | 없음 / 소문 / 증언 / 문서. 증거가 강할수록 폭로가 잘 먹힌다 |
| 아는 사람 | 인물 목록. 각자 증거 수준을 따로 가진다 |

## 2. 종류

| 비밀 | 생성 시점 | 기본 무게 | 공개 시 결과 |
|---|---|---|---|
| 사생아 | 혼외 출산 | 40 | 아이 상속권 박탈, 배우자 원한 +50 |
| 불륜 | 혼외 연인 관계 | 30 | 배우자 원한 +40, 교리 위반이면 교단 처벌 |
| 살인 | 사람을 죽였는데 목격되지 않음 | 50 | 피해자 가문 원한, 법에 따라 처벌 |
| 근친 | 교리나 법이 금하는 혼인, 관계 | 40 | 교단 처벌, 아이 정통성 하락 |
| 배교 | 공개 종교와 실제 신앙이 다름 | 35 | 교단 파문, 신도 호감 하락 |
| 도적 과거 | 도적단 수장, 구성원이었음 | 30 | 정통성 -30 |
| 비밀 후원 | 집단 간 비밀 후원 관계 | 45 | 후원자 명성, 정통성 하락. 피해 집단과 적대 |
| 횡령 | 맡은 재산을 빼돌림 | 25 | 고용주 원한, 계약 해지 |
| 음모 가담 | 반란, 암살 음모 참여 | 70 | 대상의 체포 사유 |
| 위조 | 위조 문서 제작, 사용 | 60 | 위조로 얻은 것 무효 |
| 고해 내용 | 고해 듣기로 사제가 알게 된 비밀 | 원래 비밀 무게 | 사제가 누설하면 사제 지위 박탈 |
| 혈통 위조 | 족보 위조, 남의 아이를 자기 혈통으로 | 80 | 상속 무효. 점수 계산은 실제 혈통 그대로 |

**무게 보정**: 주인의 지위가 높을수록 무게가 커진다. `실제 무게 = 기본 무게 × (1 + 주인 권력 / 100)`. 법과 교리가 그 행위를 금지하면 1.5배, 허용하면 0.3배. 예를 들어 일부다처 교리 아래에서 첩은 비밀이 되지 않는다.

## 3. 인지 경로

| 경로 | 얻는 증거 |
|---|---|
| 직접 목격(가담, 동거, 하인) | 증언 |
| 소문 나누기 | 소문 |
| 비밀 캐기 | 소문 또는 증언 |
| 심문, 고문 | 증언 |
| 고해 듣기 | 증언 |
| 문서 획득(약탈, 절도) | 문서 |
| 외형 닮음 추론(사생아) | 소문. 예민한 감각 형질이 있으면 확률 2배 |

하인과 노예는 주인 집에서 일어나는 일을 매주 일정 확률로 목격한다. 사람을 부릴수록 비밀이 샌다.

## 4. 아는 사람이 하는 일

아는 사람은 매주 비밀마다 아래 중 하나를 고른다.

| 선택 | 조건 |
|---|---|
| 침묵 | 기본값 |
| 소문 퍼뜨리기 | 사교 성격, 주인에 대한 호감 낮음 |
| 협박 | 야심 또는 탐욕, 의지 12 이상, 주인에 대한 두려움 낮음 |
| 폭로 | 정직 성격, 또는 원한 60 이상 |
| 거래 | 주인의 적에게 판다. 탐욕 성격 |
| 주인에게 알림 | 충직 성격, 주인에 대한 호감 높음. "당신 비밀을 아는 사람이 있다"고 알려 줌 |

**발설 확률(주당)**

```
기본 1%
× (1 + 원한 / 50)
× (1 - 주인에 대한 충성 / 150)
× (1 - 주인에 대한 두려움 / 150)
× 성격 배수 (사교 1.5, 내향 0.7, 정직 1.3, 기만 0.8)
× 가훈 '침묵의 맹세' 해당 시 0.5
```

## 5. 폭로의 효과

폭로가 먹히는지는 증거가 정한다.

| 증거 | 믿는 비율 |
|---|---|
| 소문 | 듣는 사람 중 주인에 대한 호감이 0 미만인 사람만 |
| 증언 | 증인의 신뢰도에 비례. 노예, 범죄자의 증언은 절반 |
| 문서 | 거의 모두. 위조 의심 판정만 남음 |

믿은 사람 비율만큼 공개 결과가 적용된다. 비밀은 반쯤 공개될 수 있다.

## 6. 비밀 관리 수단

주인이 쓸 수 있는 대응.

| 대응 | 효과 | 새로 생기는 문제 |
|---|---|---|
| 입막음(뇌물) | 아는 사람 발설 확률 감소 | 뇌물 비밀 생성. 탐욕이면 재요구 |
| 위협 | 두려움 증가 | 원한 증가 |
| 제거 | 아는 사람 사망 | 살인 비밀 생성 |
| 매수해서 내 편 만들기 | 관직, 혼인으로 이해관계 묶기 | 그 인물 권력 증가 |
| 증거 인멸 | 문서 파기 | 파기 과정 목격 위험 |
| 선수 쳐서 공개 | 스스로 공개해서 무게 절반 | 즉시 일부 손실 |
| 법, 교리 바꾸기 | 그 행위를 합법으로 만듦 | 입법 비용, 구성원 반응 |

마지막 줄이 집단 시스템과 비밀 시스템을 잇는다. 권력을 잡으면 자기 비밀을 비밀이 아니게 만들 수 있다.

# 17. 그래픽 표현과 절차 생성 구상

구현 전 구상이다. 순서는 주민 → 집 → 지형 → 마을이다. 각 알고리즘은 따로 띄워 보는 뷰어로 먼저 확인한다(7절).

## 0. 원칙

1. **단순하고 귀엽게.** 블록 몸체, 큰 머리, 단색 면 위주. 디테일을 늘려서 어색해지는 것보다 덜어내서 읽기 쉬운 쪽을 고른다.
2. **위계는 실루엣으로 읽힌다.** 멀리서도 왕궁, 저택, 가옥, 움막이 크기, 지붕 높이, 재료 색으로 구분돼야 한다. 위계를 알리는 요소는 고정하고, 나머지에서 변주한다.
3. **변주는 의미 있는 변수에서 나온다.** 무작위 색을 뿌리지 않는다. 사람 얼굴은 유전자에서, 옷은 계층과 생업에서, 집 재료는 그 지역 자원에서, 집 모양은 그 집안의 재산, 성격, 생업, 증축 이력에서 나온다. 그래서 반복이 줄고, 보이는 것이 곧 정보가 된다.
4. **같은 시드면 같은 모습.** 모든 외형은 `hash(세계 시드, 대상 id, 용도)`로 정한다. 저장할 것은 바뀐 상태(나이, 증축, 낡음)뿐이다.

## 1. 렌더링 방식

### 1-1. 결정: 3D 블록 모델 + 직교 카메라

| 방식 | 장점 | 단점 |
|---|---|---|
| 2D 아이소메트릭 스프라이트(좀보이드 방식) | 손그림 질감 | 사람 외형 조합, 집 모양 조합마다 방향별 스프라이트를 그려야 한다. 절차 변주가 사실상 막힌다 |
| **3D 블록 모델 + 직교 카메라** | 화면은 2.5D 아이소메트릭으로 같다. 몸 파츠와 집 모듈을 코드로 조합하니 변주가 공짜다. 조명, 낮밤, 회전, 지붕 걷어내기가 쉽다 | 손그림 질감이 덜하다. 텍스처와 팔레트로 보완한다 |

변주가 이 게임의 핵심 요구라서 3D 블록 모델로 간다. 화면 느낌은 2.5D를 유지한다.

### 1-2. 카메라

- `Camera3D` 직교 투영. 아래로 30°(게임식 2:1 아이소메트릭), 수평 45°.
- 90°씩 돌리기(Q/E). 줌 3단계: 가까이(주민 얼굴이 보임), 중간(마을), 멀리(셀 전체).
- 선택한 주민이 집 안에 있으면 그 집 지붕과 앞벽을 반투명으로 걷어낸다(심즈 방식).

### 1-3. 단위

지금 지역 맵 타일(16m)은 집보다 커서 화면용으로 거칠다. 화면에는 단위를 하나 더 둔다.

| 단위 | 크기 | 쓰임 |
|---|---|---|
| 셀 | 1km | 세계 맵, 토지(06번) |
| 필지 | 128m | 소유, 경작(14번) |
| 타일 | 16m | 시뮬레이션 위치, 채집 개체 단위(13번) |
| **블록** | 2m | 지형 높이와 표면. 타일 하나 = 8×8 블록 |
| **모듈** | 0.5m | 집 벽, 창, 문, 지붕 조각. 블록 하나 = 4×4 모듈 |

지형 높이는 블록마다 0.5m 단위 계단이다. 계단식 언덕이 귀여운 인상을 준다.

### 1-4. 그리기 구조 (Godot 4)

| 대상 | 노드 | 방식 |
|---|---|---|
| 지형 | 32×32 블록 청크마다 `MeshInstance3D` | 높이맵에서 윗면과 옆면만 만든다. 색은 꼭짓점 색 + 재료 텍스처 |
| 물 | 청크마다 평면 하나 | 단순 물결 셰이더 |
| 나무, 바위, 광맥, 덤불 | 종류마다 `MultiMeshInstance3D` | 종류당 절차 생성 메시 6~10개, 크기, 회전, 색 변주 |
| 집 | 집마다 생성한 `ArrayMesh` 하나 | 모듈을 붙여 한 메시로 합친다. 같은 서명이면 캐시 |
| 주민 | 사람마다 `Node3D` + 파츠 메시 | 색, 얼굴, 크기는 인스턴스 셰이더 변수. 수백 명이 넘으면 파츠별 `MultiMesh`로 바꾼다 |

재질은 몇 개만 공유한다. 텍스처 아틀라스 하나 + 꼭짓점 색 틴트로 집과 지형을 그린다. 그리기 호출을 적게 유지한다.

## 2. 주민 생성

### 2-1. 몸

| 파츠 | 기본 크기(가로 × 세로 × 깊이, 모듈 0.5m 기준 아님, 머리 높이 = 1) | 비고 |
|---|---|---|
| 머리 | 1.0 × 1.0 × 1.0 | 정면에 얼굴 그림 |
| 머리카락 | 머리 위 덮개 + 뒤, 옆 조각 | 머리 모양별 메시 |
| 몸통 | 0.9 × 0.9 × 0.55 | 옷 색 |
| 팔 ×2 | 0.3 × 0.8 × 0.3 | 소매 색 + 손 피부색 |
| 다리 ×2 | 0.35 × 0.7 × 0.35 | 바지, 치마 색 + 신발 |

- 성인 전체 키는 머리 약 2.6개. 실제보다 머리가 커서 귀엽다.
- 어른 기준 실제 키는 키 유전자(1~10)로 1.5~1.9m 사이를 정하고, 화면 크기는 0.9~1.1배로만 반영한다. 차이가 너무 크면 어색하다.

**나이 단계**

| 나이 | 비율 | 표시 |
|---|---|---|
| 0~2 | 머리 1.3배, 몸 0.5배 | 어른이 안고 다닌다 |
| 3~12 | 머리 1.15배, 몸 0.7배 | |
| 13~15 | 머리 1.05배, 몸 0.9배 | |
| 16~44 | 기준 | |
| 45~59 | 기준 | 머리카락 회색 섞임 시작(나이에 따라 0~50%) |
| 60+ | 몸 0.95배, 상체 5° 굽음 | 머리카락 회색 50~100%, 남성 대머리 확률 40%, 70세 이상 지팡이 |

### 2-2. 유전자 → 외형

01번 1절의 외형 유전자 6개를 그대로 쓴다. 가족이 닮아 보이는 것이 곧 05번 비밀 시스템의 "외형 닮음" 단서다.

| 유전자 | 값 | 외형 |
|---|---|---|
| 피부색 | 1~5 | 피부 팔레트 5색. 사람마다 명도 ±3% 흔들기 |
| 머리색 | 검정, 갈색, 금발, 적발 | 4색 계열 × 명도 5단계(시드). 노화로 회색 섞임 |
| 눈색 | 갈색, 녹색, 청색 | 눈동자 색. 얼굴 그림의 눈동자 영역을 셰이더가 칠한다 |
| 키 | 1~10 | 다리, 몸통 세로 0.9~1.1배 |
| 얼굴형 | 6종 | 머리 가로 × 세로 비(0.9~1.1), 눈 간격, 눈 높이 조합 6가지 |
| 골격 | 가냘픔, 보통, 단단함 | 몸통 가로 0.85 / 1.0 / 1.15, 팔 굵기 같은 비 |

**형질과 상태 표시**

| 대상 | 표시 |
|---|---|
| 거구 | 전체 1.12배, 몸통 가로 1.2 |
| 왜소 | 전체 0.9배 |
| 미모 | 눈 반짝임 그림, 볼 홍조 |
| 추형 | 짝눈 그림, 눈썹 굵게. 귀여움을 해치지 않을 만큼만 |
| 병약 | 피부 채도 -15% |
| 광기 발병 | 머리카락 헝클어진 변형 |
| 임신 | 몸통 앞쪽 볼록 |
| 부상 | 붕대 조각 |
| 이력: 낙인, 신체형 | 얼굴 낙인 그림, 한쪽 손 없음 |
| 이력: 고문 생존자, 결투 승자 | 흉터 그림 |

### 2-3. 유전이 아닌 것

| 요소 | 정하는 것 |
|---|---|
| 머리 모양 | 성별별 8종. 문화(나라나 부족)마다 선호 분포가 다르다. 자녀는 50% 확률로 같은 성별 부모와 같은 모양 |
| 수염 | 성인 남성. 없음, 짧은, 긴, 콧수염, 구레나룻 5종. 성격 보정: 만족, 독실은 긴 수염 쪽 |
| 옷 모양 | 생업으로 정한다: 농부 튜닉, 장인 앞치마, 사제 긴 옷, 상인 조끼, 병사 누비옷, 기사 갑옷 조각, 노예 거친 천 |
| 옷 색 | 계층이 정한다(아래 표). 같은 계층 안에서는 가문 색 하나 + 개인 색 하나 |
| 소품 | 생업 도구 손에 들기(낫, 망치, 경전, 창), 모자(농부 밀짚, 사제 두건, 귀족 장식) |

**계층별 옷 색**

| 계층 | 색 규칙 |
|---|---|
| 노예, 무산 | 염색 안 한 천: 베이지, 회갈색 2~3톤. 기운 자국 |
| 소작농, 자영농 | 흙빛 염료: 갈색, 올리브, 탁한 청색 |
| 장인, 상인 | 중간 채도: 주황, 녹색, 청색 |
| 지주, 기사 | 높은 채도 + 테두리 장식 색 |
| 귀족, 왕족 | 비싼 염료(적, 자, 청) + 금색 장식 |
| 사제 | 교단 색. 교단을 만들 때 고른다 |

옷 색은 그 사람의 실제 의류 등급(02번 품목)과 연결한다. 가난한 집이 비싼 옷을 입고 있으면 그건 약탈품이거나 비밀이다.

### 2-4. 얼굴

머리 정면 하나에 그림 4장을 겹친다: 눈, 눈썹, 입, 덧그림(홍조, 주름, 흉터, 낙인). 그림은 텍스처 아틀라스 칸 번호로 고른다.

| 그림 | 종류 | 고르는 것 |
|---|---|---|
| 눈 | 8 | 얼굴형 유전자가 2~3종 후보를 정하고 시드로 하나 |
| 눈썹 | 6 | 시드. 성격 보정(잔인, 성급은 치켜 올라간 눈썹 쪽) |
| 입 | 8 | 평소는 시드. 감정 상태에 따라 바뀐다: 스트레스 70 이상이면 찡그림, 연회 중이면 웃음 |
| 덧그림 | 6 | 상태와 이력 |

표정이 상태를 보여 준다. 숫자를 열지 않아도 굶거나 스트레스가 높은 가구원이 보인다.

### 2-5. 반복 방지

**조합 수**: 피부 5 × 머리색 20 × 눈 3 × 키 10 × 얼굴형 6 × 골격 3 × 머리 모양 8 × 수염 5 × 눈 그림 3 × 눈썹 6 × 입 8 × 옷 색 약 30 = 약 5억. 조합만으로는 반복이 거의 없다.

**문제는 "닮아 보이는" 반복이다.** 멀리서 보는 사람은 실루엣과 큰 색면(머리색, 옷 색)만 본다. 그래서 외형 서명을 정의한다.

```
서명 = (머리색 계열, 머리 모양, 옷 모양, 옷 주색, 키 3단계, 골격)
```

- 같은 셀 안에서 서명이 같은 사람은 최대 2명. 셋째부터는 유전이 아닌 요소(머리 모양, 옷 주색) 중 하나를 다시 뽑는다.
- 가족은 예외다. 형제가 닮는 것은 의도한 결과다. 다만 같은 가구 안에서는 머리 모양이나 옷 색 중 하나는 다르게 한다.

### 2-6. 움직임

- 뼈대 없이 파츠 회전만 쓴다. 걷기: 팔다리 흔들기 ±25°, 몸통 위아래 출렁임. 일하기: 생업 동작 4종(내려치기, 휘두르기, 숙이기, 두드리기).
- 동작은 몸 전체가 시차를 두고 따라 움직이게 만든다. 머리는 몸통보다 한 박자 늦게, 팔은 반대쪽 다리와 함께 흔든다.
- 사람마다 동작 속도 ±10%, 시작 위상 무작위. 군중이 같은 박자로 움직이지 않게 한다.

## 3. 집 생성

### 3-1. 생성 문법

집 하나는 아래 순서로 만든다. 단계마다 등급이 정한 범위 안에서 시드와 가구 정보로 고른다.

1. **평면**: 사각, L자, T자, U자, ㅁ자(안뜰)
2. **층수와 높이**
3. **벽**: 재료와 구조(통나무, 나무 틀 + 회벽, 돌 기단 + 회벽, 돌, 벽돌)
4. **개구부**: 문 위치(도로 쪽 면 우선), 창 수와 배치(벽 길이 3모듈마다 후보, 규칙적 또는 불규칙)
5. **지붕**: 모양(원뿔, 외쪽, 맞배, 우진각, 탑 지붕)과 재료(초가, 너와, 기와, 슬레이트), 처마 깊이
6. **부속물**: 굴뚝, 차양, 창고, 헛간, 장작더미, 우물, 울타리, 텃밭, 닭장, 작업장
7. **낡음**: 지붕 기운 자국, 이끼, 벽 얼룩, 깨진 창. 집의 남은 내구(15번 1-7)에 비례

### 3-2. 등급별 범위

**위계 신호(고정)**는 실루엣으로 바로 읽히게 정해 둔다. **자유 변수**에서만 변주한다.

| 등급 | 위계 신호(고정) | 자유 변수 |
|---|---|---|
| 움막 | 바닥 2×2~3×3 블록, 1층 낮음(벽 2m), 초가 또는 나뭇가지 지붕, 창 0~1, 굴뚝 없음(연기 구멍) | 평면 사각/원형, 지붕 원뿔/외쪽, 벽 재료(지역), 문 방향, 장작더미, 울타리 유무 |
| 가옥 | 바닥 3×4~4×6 블록, 1층 + 다락, 맞배 지붕, 너와 또는 짚, 창 2~4, 굴뚝 1 | 평면 사각/L, 벽 구조 3종(지역), 지붕 경사, 창 배치, 부속물 2~3개(생업), 증축 방(H4) 0~2 |
| 저택 | 바닥 8×10 블록 이상, 2층, 기와 또는 슬레이트, 돌 기단, 창 8개 이상 규칙 배치, 굴뚝 2~3, 담과 대문 | 평면 L/U/ㅁ, 탑 유무, 지붕 우진각/맞배, 정원 모양, 별채(H4) 0~3, 장식 색 |
| 왕궁 | 건물 여러 채 + 성벽 + 탑, 안뜰, 가장 높은 지붕, 깃발 | 건물 배치(중심형, 일자형, 산세형), 탑 수, 지붕 색, 정원, 예배당 |

**실루엣 검사**: 등급마다 생성한 집 100채의 부피와 지붕 꼭대기 높이 범위가 서로 겹치지 않아야 한다. 겹치면 고정값을 조정한다.

### 3-3. 지역 양식

이웃집들이 서로 닮되 똑같지 않게, **지역 양식**이 공통 바탕을 준다.

- **재료는 그 지역 자원에서 나온다.** 집을 지을 때 쓴 재료(15번 1-5 H3)가 그대로 외형이 된다. 숲 셀은 통나무 벽, 구릉과 암석지대는 돌 벽, 강변과 늪은 갈대 지붕, 평야는 나무 틀과 회벽.
- **문화 팔레트**: 나라나 부족을 만들 때 시드로 양식 묶음을 하나 정한다. 지붕 경사 범위, 회벽 색 2~3개, 문과 창틀 색 2~3개, 장식 무늬 1개. 같은 나라 안의 마을은 같은 묶음을 쓴다.
- 나라가 바뀌면(정복, 독립) 새로 짓는 집부터 양식이 바뀐다. 오래된 마을에 두 양식이 섞여 있으면 역사가 보인다.

### 3-4. 집안마다 다른 것

| 집안 정보 | 외형 |
|---|---|
| 생업 | 대장장이: 화덕 굴뚝과 작업장. 농부: 헛간과 건초더미. 상인: 앞쪽 가게 차양. 사제: 작은 사당. 장인: 작업장 별채 |
| 성격(가구주) | 야심: 장식 색 하나 더, 큰 문. 만족, 근면: 텃밭과 장작더미. 관대: 앞마당 의자. 내향: 높은 울타리 |
| 재산 변화 | 증축하면 방이 붙는다(H4). 몰락하면 낡음이 쌓인다(유지비 미납) |
| 나이 | 지은 지 오래될수록 낡음. 수리하면 새 재료 색이 덧대어진다 |
| 가문 | 가문 색을 문, 창틀, 깃발에 쓴다 |

### 3-5. 반복 방지

```
집 서명 = (평면, 지붕 모양, 지붕 재료, 벽 재료, 문 방향, 주색, 부속물 집합)
서명 거리 = 서로 다른 항목 수
```

- 생성할 때 같은 길에 붙은 이웃 4채와 서명 거리가 2 미만이면, 자유 변수 중 문 방향, 주색, 부속물을 다시 뽑는다.
- 같은 셀 안에서 서명이 완전히 같은 집은 없게 한다.

### 3-6. 메시 만들기

- 모듈(벽 1×1, 창, 문, 지붕 조각, 굴뚝)을 0.5m 격자에 놓고 하나의 `ArrayMesh`로 합친다. 보이지 않는 면은 뺀다.
- 텍스처는 아틀라스 하나. 같은 재료 안에서 칸 2~3개를 섞어 벽 무늬가 반복되지 않게 한다.
- 서명이 같은 메시는 캐시해서 다시 쓴다.

## 4. 지형

13번 문서의 생성 단계를 그대로 쓰고, 화면으로 옮기는 부분만 더한다.

### 4-1. 화면 표현

| 요소 | 표현 |
|---|---|
| 높이 | 블록(2m)마다 높이 0.5m 단위 계단. 세계 맵 고도 + 지역 미세 고도를 합쳐 반올림 |
| 표면 | 지형 분류(13번 5절)마다 윗면 재료. 경계 블록은 이웃 재료와 무작위로 섞는다 |
| 강 | 강 경로 블록을 1~1.5m 파고 물 평면. 폭 3~6타일(24~48m)은 화면에서 너무 넓어서 **화면 폭 4~12블록(8~24m)**으로 줄인다 |
| 숲 | 나무를 블루 노이즈(포아송 원반)로 뿌린다. 밀도 = 숲 밀도 × 남은 목재 비율. 베면 그루터기 |
| 돌 | 암석지대, 구릉에 바위 무리. 큰 바위 1개 주변에 작은 바위 2~5개 |
| 광석 | 광맥 특성 셀에서 노두 바위에 광석 색 점. 발견 전(13번 6절)에는 그냥 바위로 보인다 |
| 밭 | 필지마다 고랑 방향 하나. 작물 색이 계절에 따라 변한다(파종 갈색 → 초록 → 황금 → 그루터기) |

### 4-2. 검증 지표 (시드 100개로 돌림)

| 지표 | 기준 |
|---|---|
| 지형 비율 | 바다 비율 설정 ±5%, 산 5~15%, 숲 20~40%, 평야 25~45% |
| 강 | 모든 강이 바다나 호수에서 끝남. 오르막으로 흐르는 블록 0개. 셀 400개당 강 1개 이상 |
| 광맥 | 산 셀에만 있음. 산 셀의 20~30% |
| 정착지 | 모든 마을이 물(강, 호수, 해안)에서 3셀 이내 |
| 섬 | 바다 비율 30%에서 육지 덩어리 1~6개 |
| 같은 시드 | 두 번 생성한 결과가 바이트 단위로 같음 |

## 5. 마을 형성

14번 16절이 넘긴 입력(위협 수준, 필지 소유, 공유지, 보호자 거처, 장인, 시장)을 받는다.

### 5-1. 처음 만들기

1. **중심**: 마을 셀 안에서 점수 최고 블록. `점수 = 평탄도 + 물 거리 가까움 + 비옥한 필지 거리 가까움`. 중심에 우물이나 공터를 둔다.
2. **큰길**: 중심에서 이웃 정착지와 교역로 방향으로 길을 낸다. A* 경로 비용 = 1 + 경사 × 3 + 숲 2 + 물 건너기 20(여울이나 다리를 만듦).
3. **집터**: 큰길 양옆에 길에 면한 집터를 줄지어 나눈다. 집터 폭은 등급마다 다르다(움막 4블록, 가옥 6블록, 저택 14블록 이상). 집은 길 쪽으로 문을 낸다.
4. **밭**: 가구마다 소유 필지(14번 2-1)를 밭으로 그린다. 집터 뒤에서 바깥쪽으로 퍼진다. 공유지는 마을 바깥 숲, 풀밭.

### 5-2. 집촌과 산촌

위협 수준(14번 8-1)이 마을 모양을 정한다.

| 위협 | 모양 |
|---|---|
| 낮음 (연 약탈 기대 손실 < 수확의 2%) | 산촌. 자영농 집이 자기 필지 가장자리에 흩어지고, 오솔길로 큰길에 잇는다 |
| 중간 | 길 따라 늘어선 마을(가로 마을) |
| 높음 (5% 이상) | 집촌. 중심 반경 안에 빽빽이 모이고 목책을 친다. 밭까지 걸어 나간다 |

위협이 바뀌면 새 집부터 다른 규칙으로 짓는다. 오래된 산촌 위에 목책 친 집촌이 덧붙는 식으로 역사가 쌓인다.

### 5-3. 확장 규칙

새 가구(분가, 이주)가 집터를 고를 때:

```
집터 점수 = - (자기 밭까지 거리) × 2
           - (부모 집까지 거리) × 1        (가족 근처 선호)
           + (큰길에 면함) × 5
           - (같은 등급 집이 아닌 이웃) × 1 (비슷한 집끼리 모이는 경향)
           + (등급 3 이상이면 높은 곳, 넓은 집터) × 5
```

1. 기존 길가 빈 집터 중 점수 최고를 고른다.
2. 길가가 다 찼으면 길을 늘린다: 큰길 끝을 6블록 연장하거나, 큰길에서 직각으로 골목을 낸다(골목 간격 최소 12블록). 둘 중 밭과 가까운 쪽.
3. 저택은 큰길에서 조금 물러나 정원을 둔다. 왕궁, 성채는 마을 안 가장 높은 곳이나 교역로가 보이는 언덕.
4. 시설: 대장간은 큰길가, 사당은 중심, 물레방아는 강가, 시장은 화폐화율 30% 이상이면 중심 공터에 연다.
5. 버려진 집(가구 소멸, 이주)은 해마다 낡음이 쌓여 10년 뒤 폐허, 20년 뒤 빈 집터가 된다.

### 5-4. 검증 지표

| 지표 | 기준 |
|---|---|
| 겹침 | 집, 길, 밭 사이 겹침 0 |
| 연결 | 모든 집이 길로 마을 중심에 닿는다 |
| 밭 거리 | 가구의 집에서 자기 밭까지 평균 거리: 산촌 100m 이하, 집촌 400m 이하 |
| 길 모양 | 막다른 골목 비율 30% 이하. 각 골목 길이 1블록 이상 |
| 성장 | 100년 시간 경과 영상에서 마을이 길을 따라 퍼지고, 빈 땅에 섬처럼 떨어진 집이 없다(산촌 제외) |

## 6. 데이터와 코드 구조 (Godot)

```
res://
  data/                      (지금 저장소의 data/를 그대로 씀)
    registry.json, traits/
    visual/palettes.json      피부, 머리, 옷, 재료 팔레트

  scripts/
    core/rng.gd               hash(시드, id, 용도) 결정적 난수
    gen/world_gen.gd          13번 생성
    gen/terrain_mesher.gd     청크 메시
    gen/person_look.gd        2절: 유전자 → 외형 파라미터
    gen/person_mesh.gd        파츠 조립, 셰이더 변수

  assets/textures/, fonts/, ui/
```

- 프로토타입은 GDScript로 쓴다. 인구 시뮬레이션처럼 무거운 부분은 나중에 C#이나 GDExtension으로 옮긴다.
- 시뮬레이션 수치(경제, 승계)는 `tools/econ_sim`의 파이썬 모델과 같은 공식을 쓴다. 파이썬 쪽이 검증 기준이다.

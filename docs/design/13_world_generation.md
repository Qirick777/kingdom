# 13. 세계 생성

## 1. 시드

- 시드는 문자열 또는 64비트 정수. 문자열이면 해시해서 정수로 바꾼다.
- 같은 시드와 같은 설정이면 항상 같은 세계가 나온다.
- 모든 무작위 값은 `hash(시드, 단계 번호, x, y)`로 얻는다. 생성 순서가 바뀌어도 결과가 같다.

## 2. 두 층 구조

| 층 | 단위 | 크기 | 쓰임 |
|---|---|---|---|
| 세계 맵 | 셀 1개 = 구역(토지) 1곳, 약 1km × 1km | 소 64×64 / 중 128×128 / 대 256×256 | 06_land.md의 토지 단위. 세력, 소유, 개간 단계 |
| 지역 맵 | 타일 1개 = 약 16m × 16m | 셀 1개당 64×64 타일 | 2.5D 화면. 인물 이동, 나무, 바위, 건물 |

지역 맵은 처음부터 다 만들지 않는다. 플레이어가 보거나 상세 시뮬레이션 범위에 들어온 셀만 그때 만든다. 시드가 같으니 언제 만들어도 결과가 같다. 만든 뒤 바뀐 내용(벌목, 건물)만 저장한다.

## 3. 생성 단계 (세계 맵)

| 단계 | 내용 | 방법 |
|---|---|---|
| 1. 고도 | 0~1 고도값 | 프랙털 노이즈(옥타브 5) + 대륙 마스크(가장자리를 낮춤) |
| 2. 바다 | 해수면 아래는 바다 | 해수면 = 고도 분포의 하위 % (설정: 바다 비율) |
| 3. 기온 | 0~1 | 위도(북쪽일수록 낮음) - 고도 × 0.5 + 약한 노이즈 |
| 4. 강 | 강 경로 | 아래 4절 |
| 5. 습도 | 0~1 | 노이즈 + 바다, 강, 호수와 가까울수록 높음 |
| 6. 지형 분류 | 셀마다 지형 1개 | 아래 5절 표 |
| 7. 자원 | 토지 특성 배치 | 아래 6절 |
| 8. 정착지 | 초기 마을, 읍 위치 | 아래 7절 |
| 9. 초기 역사 | 가문, 혈연, 집단, 비밀 | 아래 8절 |

## 4. 강

1. 고도 0.6 이상, 습도 0.5 이상인 셀 중 무작위로 수원을 고른다. 수원 수 = 맵 면적 / 400.
2. 수원에서 가장 낮은 이웃 셀로 계속 내려간다.
3. 더 낮은 이웃이 없으면(웅덩이) 그 셀을 호수로 만들고, 호수 가장자리 중 가장 낮은 곳에서 다시 흐른다.
4. 바다나 다른 강에 닿으면 멈춘다.
5. 셀마다 흘러 들어온 수원 수(유량)를 센다. 유량 1~2는 개울, 3 이상은 강. 강은 걸어서 건널 수 없고 다리나 여울이 필요하다.

강이 지나는 셀과 그 이웃은 "강변" 판정을 받는다.

## 5. 지형 분류

위에서부터 먼저 맞는 조건을 쓴다.

| 지형 | 조건 | 비고 |
|---|---|---|
| 바다 | 해수면 아래 | 통행 불가. 해안 어로, 교역로 경계 |
| 호수 | 강 생성 중 웅덩이 | 통행 불가. 주변 어로 |
| 해안 | 바다와 이웃 | 어로 가능. 교역로 후보 |
| 산 | 고도 0.75 이상 | 광맥 후보. 곡식 불가 |
| 암석지대 | 고도 0.55~0.75, 습도 0.35 미만 | 석재 2배. 곡식 0.5배 |
| 구릉 | 고도 0.55~0.75 | 석재 1.5배 |
| 늪 | 고도 0.45 미만, 습도 0.75 이상 | 섬유, 질병 |
| 숲 | 습도 0.5 이상 | 목재, 사냥 |
| 강변 | 강이 지나감 (위 조건에 덮어씀, 산 제외) | 비옥, 교역 |
| 평야 | 나머지 | 곡식 |

기온은 지형 위에 보정으로 붙는다. 기온 0.25 미만이면 "한랭": 곡식 -30%, 겨울 의류 필요 2배.

## 6. 자원과 토지 특성 배치

| 특성 | 배치 규칙 |
|---|---|
| 광맥 | 산 셀마다 25% 확률. 발견 전에는 숨겨짐(채집 50 또는 탐사 행동) |
| 비옥함 | 강변, 평야 중 습도 0.6 이상의 50% |
| 사냥터 | 숲 셀 중 사람 사는 곳에서 3셀 이상 떨어진 곳 |
| 은신처 | 숲, 산, 늪 셀 중 길에서 먼 곳 15% |
| 교역로 | 정착지 생성 후, 읍끼리 잇는 최단 경로(강변, 해안 우선) |

## 7. 정착지

1. 셀마다 정착 점수를 매긴다: `비옥함 + 강변 + 해안 + 숲 인접 - 늪 - 산`.
2. 점수 높은 순서로 마을을 놓는다. 마을끼리 최소 4셀 간격(포아송 원반 배치).
3. 마을 수의 10%를 읍으로 올린다. 교역로가 교차하는 곳 우선.
4. 읍 사이를 잇는 길을 깐다. 이 길이 교역로 특성의 바탕이 된다.

## 8. 초기 역사

세계를 빈 상태로 시작하면 혈연도 비밀도 없다. 그래서 시작 전에 **요약 시뮬레이션으로 80년**을 미리 돌린다.

1. 정착지마다 시조 가문 3~8개를 놓는다. 시조들의 형질 대립유전자는 기본 보유율대로 뿌린다.
2. 요약 상세도로 80년을 돌린다. 출생, 혼인, 사망, 집단 창설, 전쟁만 계산한다.
3. 결과로 혈연망, 나라, 교단, 도적단, 비밀(사생아, 살인 등)이 생긴다.
4. 플레이어는 이 세계에서 시작 인물을 고른다. 시작 인물이 그 순간 시조가 되어 r = 1이 된다. 기존 친척 관계는 그대로 남는다.

시드가 같으면 초기 역사도 같다.

## 9. 지역 맵 생성 (셀 → 64×64 타일)

| 단계 | 내용 |
|---|---|
| 1. 바닥 | 셀 지형으로 바닥 타일을 깐다. 경계 8타일은 이웃 셀 지형과 섞는다 |
| 2. 미세 고도 | 고해상도 노이즈로 언덕, 움푹한 곳 |
| 3. 물 | 강, 개울 경로를 셀 입구, 출구에 맞춰 이어 그림. 강은 폭 3~6타일 |
| 4. 개체 | 나무(숲 밀도), 바위(암석지대, 구릉), 광맥 노두(광맥 특성), 덤불(섬유) |
| 5. 사냥감 | 동물 무리 스폰 지점 |
| 6. 구조물 | 마을이면 가옥, 창고, 사당을 길 따라 배치 |

채집 행동은 이 개체를 실제로 소모한다. 나무를 베면 그루터기가 남고 몇 년 뒤 다시 자란다. 숲을 다 베면 그 셀의 목재 산출이 떨어진다. 세계 맵 수치와 지역 맵 개체 수를 연동한다.

## 10. 생성 설정

| 설정 | 선택지 |
|---|---|
| 시드 | 자유 입력 / 무작위 |
| 크기 | 소, 중, 대 |
| 바다 비율 | 10% / 30% / 50% |
| 대륙 형태 | 단일 대륙 / 군도 / 내륙(바다 없음) |
| 강 수 | 적음 / 보통 / 많음 |
| 기후 | 한랭 / 온대 / 온난 |
| 초기 역사 | 없음 / 80년 / 200년 |
| 초기 세력 수 | 나라, 교단, 도적단 수 |

## 11. Godot 구현 메모

- 노이즈: Godot 4 `FastNoiseLite` (Simplex, Fractal FBM). 단계마다 다른 시드 오프셋.
- 지역 맵: `TileMapLayer` 아이소메트릭 모드. 셀 단위 청크로 불러오고 내린다.
- 결정성: 전역 난수를 쓰지 않는다. 단계별로 `RandomNumberGenerator`를 `hash(시드, 단계, x, y)`로 초기화한다.
- 세계 생성과 초기 역사 시뮬레이션은 별도 스레드에서 돌리고 진행률을 표시한다.

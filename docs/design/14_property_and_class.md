# 14. 재산과 계층의 발생

## 0. 목표

계층을 배치하지 않는다. 생산, 저장, 보호, 상속 규칙만 두고, AI가 그 안에서 자기 이익을 따라 움직이면 신분 피라미드가 저절로 생기게 한다. 피라미드가 생기는 조건과 무너지는 조건을 모두 규칙 안에 넣는다.

피라미드는 세 질문의 답으로 정해진다.

1. **누가 먹고 남기는가**: 잉여(2절)
2. **남은 것을 누가 가져가는가**: 청구권의 층(3절)
3. **그 청구를 누가 강제하는가**: 보호와 강제력(8절)

세 질문 모두 기술, 땅의 여유, 무력의 값, 화폐에 따라 답이 바뀐다. 그래서 같은 규칙에서 지역마다 다른 사회가 나온다.

---

## 1. 재산의 정의

재산은 물건과 권리의 묶음이다. 필지 하나에 여러 사람이 서로 다른 권리를 동시에 가질 수 있다.

### 1-1. 권리 5종

| 권리 | 뜻 |
|---|---|
| 사용권 | 직접 쓰고 경작한다 |
| 수익권 | 산출의 일부를 받는다(소작료, 세금, 헌물) |
| 처분권 | 팔고, 저당 잡히고, 준다 |
| 상속권 | 자식에게 넘긴다 |
| 배제권 | 남이 못 쓰게 막는다 |

| 보유자 | 가진 권리 |
|---|---|
| 자영농 | 다섯 가지 모두 |
| 소작농 | 사용권 |
| 지주 | 수익권(소작료), 처분권, 상속권, 배제권 |
| 영주 | 수익권(세금), 재판권, 징병권 |
| 교단 | 수익권(헌물) |

필지 하나를 소작농이 갈고, 지주가 소작료를 받고, 영주가 세금을 걷고, 교단이 헌물을 받는다. 이 겹침이 피라미드의 실체다.

### 1-2. 재산 종류

| 분류 | 예 |
|---|---|
| 동산 | 품목(곡식, 도구, 무기), 은화 |
| 부동산 | 필지, 집터, 시설 |
| 채권 | 빚 문서, 대여 기록 |
| 계약상 권리 | 소작료 받을 권리, 고용 관계 |
| 영주권 | 징세권, 재판권, 징병권, 통행세권 |
| 사람 | 노예, 농노의 부역 |
| 무형 | 위신, 기법 비밀, 독점권, 관직 |

### 1-3. 인정 강도

재산은 남들이 인정해야 지켜진다. 필지마다 소유 주장의 **인정 강도**를 계산한다.

| 근거 | 점수 |
|---|---|
| 직접 개간 | 30 |
| 관습상 상속 | 20 |
| 10년 이상 점유, 경작 | 20 |
| 증서(학문 30 이상인 사람이 작성. 위조 가능) | 30 |
| 영주, 나라의 보증 | 보증자 강제력 / 10 |
| 교단 등록 | 10 (같은 교단 신도 사이에서만) |
| 무력 점유 | 실제로 차지한 쪽 무장 인원 × 3 |

분쟁이 나면 판관이 있을 때는 인정 강도와 판관의 편향으로 정한다. 판관이 없으면 무력으로 정한다.

**결론**: 판관이 없는 곳에서 약자의 재산은 늘 위태롭다. 이 불안이 보호자와 판관을 찾는 수요를 만든다(8절).

## 2. 생산과 잉여

### 2-1. 필지

- 셀(64×64 타일)을 8×8 타일 필지 64개로 나눈다. 필지 하나는 약 1.6ha다.
- 필지 상태: 숲, 황무지, 경작지, 휴경지, 집터, 시설터, 공유지.
- 소유, 경작, 청구는 필지 단위로 기록한다.
- 셀의 개간 단계(06_land.md)는 경작지 필지 수와 시설로 자동 결정된다.

**개간**: 필지 1개 = 4 인·주 × 지형 난이도. 하급 도구 필요. 숲 필지를 개간하면 목재 30이 나온다.

**경작 면적**: 성인 1명이 경작할 수 있는 필지 수는 도구가 정한다. 맨손 1, 하급 도구 2, 상급 도구 3.

### 2-2. 수확

수확은 1년에 한 번, 가을에 들어온다.

```
필지 수확 = 40 × 지형 배수 × 특성 배수 × (1 + 농사 기술 / 200) × 작황
```

| 작황 | 확률 | 배수 |
|---|---|---|
| 풍년 | 20% | 1.3 |
| 평년 | 55% | 1.0 |
| 흉년 | 20% | 0.6 |
| 대흉년 | 5% | 0.3 |

- 작황은 **지역 단위**로 정한다. 인접 셀 묶음이 같은 해에 같은 작황을 겪는다. 흉년에는 이웃도 같이 굶으니 이웃끼리 서로 돕지 못한다. 곡식을 쌓아 둔 집이나 먼 곳에서 실어 오는 상인만 도울 수 있다.
- **종자**: 봄 파종 때 필지당 곡식 8이 든다. 종자가 없으면 경작하지 못한다. 굶주린 가구 AI는 허기 2주 이상이면 종자에 손을 댄다. 그러면 다음 해 경작을 못 해 빚을 지게 된다.

### 2-3. 잉여 계산

가족 5명(성인 2, 아동 3)의 연간 소비는 `2 × 48 + 3 × 24 = 168`이다. 청구(세금, 소작료)는 빼지 않았다.

| 조건 | 경작 필지 | 순수확(종자 뺌) | 잉여 |
|---|---|---|---|
| 평야, 맨손, 평년 | 2 | 104 | **-64** |
| 평야, 하급 도구, 평년 | 4 | 208 | **+40** |
| 평야, 하급 도구, 풍년 | 4 | 280 | +112 |
| 평야, 하급 도구, 흉년 | 4 | 112 | **-56** |
| 평야, 상급 도구, 평년 | 6 | 312 | **+144** |
| 구릉, 하급 도구, 평년 | 4 | 96 | -72 |
| 강변 + 비옥함, 하급 도구, 평년 | 4 | 238 | +70 |

여기서 세 가지가 나온다.

1. **맨손 농사로는 가족을 못 먹인다.** 사냥, 채집과 섞어야 한다. 하급 도구가 농경 사회의 문을 연다.
2. **하급 도구 자영농의 잉여는 연 40, 순수확의 약 19%다.** 흉년 한 번에 잉여 1.4년치를 잃는다. 저장 없는 가구는 흉년마다 빚을 진다.
3. **상급 도구는 잉여를 3.6배로 만든다.** 사회가 먹일 수 있는 비농민의 수가 그만큼 늘어난다.

구릉, 암석지대 가구는 농사만으로 못 산다. 석재, 목재, 사냥감을 곡식과 바꿔야 한다. 지형이 분업을 강제한다.

### 2-4. 피라미드의 폭

비농민(영주, 기사, 장인, 사제, 병사, 상인)은 농민의 잉여로 먹고산다. 그래서 비농민 비율의 상한은 잉여율이 정한다.

| 기술 수준 | 농가 1호의 잉여 | 비농민 가구 상한 |
|---|---|---|
| 하급 도구 | 40 | 전체 가구의 약 20% |
| 상급 도구 | 144 | 전체 가구의 약 45% |

이 상한을 넘어 청구하면 농민이 굶는다. 기술이 오르면 피라미드 윗부분이 넓어질 수 있다. 무장 전문가, 장인, 관료, 사제가 늘어난다.

## 3. 수확 청구권의 층

### 3-1. 분배 순서

가을 정산 때 필지 수확은 아래 순서로 나뉜다.

1. 종자 보존
2. 교단 헌물 (헌물 의무 교리: 순수확의 10%)
3. 영주 세금 (징세권자. 법이 정한 비율)
4. 지주 소작료 (소작 필지일 때)
5. 빚 상환
6. 경작자 몫

### 3-2. 예시: 하급 도구, 평야, 평년, 가족 5명

| 항목 | 자영농 | 소작농 |
|---|---|---|
| 수확 | 240 | 240 |
| 종자 | -32 | -32 |
| 헌물 10% | -21 | -21 |
| 세금 10% | -21 | -21 |
| 소작료 1/3 | | -69 |
| 경작자 몫 | 166 | 97 |
| 소비 168 대비 | -2 | **-71** |

- 자영농은 청구를 내고 나면 잉여가 거의 없다. 세금과 헌물이 곧 사회의 잉여다.
- 소작농은 소작료만큼 모자란다. 부업(섬유, 의류, 날품, 채집)으로 메우거나 아이를 덜 키운다.
- **계층이 출산과 생존을 바꾼다.** 땅을 가진 집은 아이가 더 많이 살아남는다. 혈통 점수가 경제 계층과 바로 이어진다.

### 3-3. 청구의 상한

청구의 합이 잉여를 넘으면 경작자가 굶는다. 굶은 경작자는 도망가거나 봉기하거나 죽는다. 그러면 다음 해 생산이 줄고 청구자의 몫도 준다.

AI 청구자는 세율과 소작료를 정할 때 이 되먹임을 계산한다. 단 탐욕, 잔인 성격 청구자는 1년 앞만 보고 과하게 걷는다. 그런 지역은 몇 년 안에 무너진다. 그것도 게임 안의 사건이다.

### 3-4. 강제력과 징수

청구는 강제할 수 있어야 걷힌다.

```
자발 납부율 = 정통성 × 0.6 + 두려움 × 0.4   (각 0~100 → %)
```

- 미납분은 청구자가 무장 인원을 보내 걷어야 한다. 징수 인원 1명이 주당 2가구를 처리한다.
- 징수 인원도 먹여야 한다. 그래서 정통성이 낮은 청구자는 징수 비용이 커서 세율을 높이지 못한다.
- 정통성이 쌓이면 같은 병력으로 더 많이 걷는다. 대를 이은 영주가 신참 영주보다 강한 이유가 여기 있다.

## 4. 재산이 생기는 경로

| 경로 | 조건 | 인정 강도 | 비고 |
|---|---|---|---|
| 개간 | 무주지, 노동, 하급 도구 | 30 | 초기 재산의 대부분. 노동력 많은 큰 가족이 유리 |
| 상속 | 부모 사망 | 20 + 부모의 강도 일부 | 상속법이 쪼갬과 집중을 정함 |
| 매매 | 판매자, 가격 | 판매자 강도 승계 | 흉년 뒤 매물이 몰림 |
| 담보 회수 | 빚 미상환 2회 | 판결이 있어야 확정 | 쏠림의 주 경로 |
| 하사(봉토) | 영주가 봉사 대가로 줌 | 영주 보증 | 조건부. 봉사를 안 하면 회수 |
| 지참금 | 혼인 | 증서 | 위신과 재산의 교환 |
| 정복, 약탈 | 무력 | 무력 점유 | 정통성이 따라오지 않음 |
| 공유지 점유 | 공유지를 개간하거나 울타리를 침 | 마을이 반발 | 가난한 집 부업 터가 사라짐 |
| 위조 | 증서 위조 | 들킬 때까지 30 | 09_crime.md |
| 유증 | 죽으면서 교단에 바침 | 교단 등록 | 독실 성격. 교단 토지 축적(11-2) |

## 5. 재산이 쏠리는 고리

| 고리 | 흐름 |
|---|---|
| 저장과 대여 | 저장 → 흉년에 빌려줌 → 담보로 땅 회수. 흉년은 지역 단위라 저장한 집만 빌려줄 수 있다 |
| 땅과 아이 | 땅 → 잉여 → 아이 생존 → 노동력 → 개간 → 땅 |
| 무장 | 무장 → 보호비, 약탈 → 무장 유지 |
| 위신과 혼인 | 위신 → 좋은 혼처 → 지참금, 동맹 → 위신 |
| 문해와 소송 | 글을 앎 → 증서 → 소송 승리 → 땅 |
| 판결 | 판결 → 수수료, 정통성 → 더 많은 사건이 몰림 |
| 관직 | 관직 → 녹봉, 뇌물 → 자녀 교육 → 관직 |

## 6. 재산이 흩어지는 고리

| 고리 | 흐름 |
|---|---|
| 분할 상속 | 부잣집은 아이가 많아 재산이 더 잘게 쪼개진다. "땅과 아이" 고리와 정면으로 부딪힌다 |
| 장자 상속의 부작용 | 쪼개짐은 막지만 땅 없는 차남을 만든다. 차남들이 병사, 사제, 도적, 개척민이 된다 |
| 엘리트 과잉 | 부잣집 아이가 늘어도 자리(봉토, 관직)는 그대로다. 남는 엘리트가 다툰다(14절) |
| 원한과 범죄 | 불평등이 클수록 도둑질, 강도, 방화가 부자를 노린다 |
| 봉기 | 경작자 몫이 생존선 아래로 2년 이상 가면 봉기군이 생길 확률이 오른다 |
| 관리 비용 | 지주의 관리 기술보다 소작인이 많으면 횡령과 미납이 늘어난다. 부재지주는 손실이 크다 |
| 교리와 법 | 자선 의무, 채무 탕감, 고리대금 금지, 노예 해방 |
| 역병, 전쟁 | 인구가 줄면 땅이 남고 노동이 귀해진다. 소작료가 떨어지고 임금이 오른다(10절) |
| 위신 지출 | 관대한 엘리트는 연회와 선물로 재산을 추종자로 바꾼다 |

**설계 목표**: 두 고리가 대략 맞서게 한다. 계층은 생기지만 한 집이 모든 것을 갖지는 않는다. 균형점은 기술, 땅의 여유, 위협, 법에 따라 움직인다.

## 7. AI 경제 행동

### 7-1. 생업 선택

성인 AI는 계절마다, 그리고 큰 사건(혼인, 상속, 파산, 해고) 때 생업을 다시 고른다. 주 생업 하나와 부업 하나를 가질 수 있다.

```
효용 = 기대 소득 × (1 - 위험) + 성격 보정 + (위신 변화 × 체면 계수) - 전환 비용
```

| 항목 | 내용 |
|---|---|
| 기대 소득 | 그 생업으로 1년에 얻을 곡식 환산 가치. 지역 가격으로 계산 |
| 위험 | 사망, 처벌, 약탈당할 확률 |
| 성격 보정 | 용감: 병사, 도적 +. 근면: 농사, 장인 +. 탐욕: 상인, 대금업 +. 독실: 사제 +. 겁많음: 병사 -. 잔인: 도적 + |
| 체면 계수 | 지금 위신이 높을수록 위신이 떨어지는 생업을 싫어한다. 기사의 아들은 굶기 직전까지 소작농이 되지 않는다. 대신 병사, 사제, 도적이 된다 |
| 전환 비용 | 도구, 기술, 시설을 새로 갖추는 비용 |

| 생업 | 필요 조건 | 기대 소득 |
|---|---|---|
| 채집, 사냥 | 공유지나 무주지 접근 | 자원 밀도 × 기술. 인구가 늘면 고갈 |
| 자영농 | 필지 소유 + 종자 | 수확 - 청구 |
| 소작농 | 소작 계약 | 수확 - 소작료 - 청구 |
| 머슴, 날품팔이 | 고용주 | 임금(7-4) |
| 장인 | 기술, 도구, 시설, 수요 | (제품 가격 - 재료비) × 생산량 |
| 상인 | 은화, 교역로 | 지역 간 가격 차 × 물량 - 운송비 - 약탈 위험 |
| 병사 | 고용주, 징집 | 녹봉 또는 숙식 + 약탈 기대 |
| 사제 | 교단 | 헌물 분배 |
| 도적 | 무리 | 약탈 기대 - 토벌 위험 |
| 대금업 | 저장 곡식, 은화 | 이자 - 떼일 위험 |
| 지주 | 필지가 가구 노동력보다 많음 | 소작료 |
| 기사 | 장비, 전투 기술, 봉토나 녹봉 | 봉토 수익 |
| 영주 | 영주권 | 세금, 판결 수수료 |

**예시: 장인이 생기는 과정**

- 하급 도구 지역 가격이 6이다(기준가 3의 2배). 재료는 목재 2개(가격 1)이고, 1주에 1개를 만든다. 개당 이익 4, 연 192다.
- 같은 사람이 하급 도구로 2필지를 경작하면 연 순수확이 104다.
- 사람들이 장인으로 옮겨 가고, 도구 값이 떨어진다. 가격이 4 안팎이 되면 두 생업의 소득이 비슷해지고 이동이 멈춘다.

**수요가 장인의 수를 정한다**: 하급 도구는 내구가 20회라 농민 1명이 1년에 2개쯤 쓴다. 농민 20명 마을의 연 수요는 약 40개로, 장인 1명이 20주 일할 양이다. 그래서 마을에는 겸업 장인이 생기고, 전업 장인은 읍 이상에서 생긴다.

### 7-2. 잉여 사용

가을 정산 뒤 잉여가 있는 AI는 이 순서로 쓴다.

1. 다음 해 종자 + 1년치 식량 저장
2. 닳은 도구 교체
3. 성격에 따른 지출

| 성격 | 3순위 지출 | 길러지는 엘리트 유형 |
|---|---|---|
| 탐욕 | 대여, 땅 매입 | 대금업자, 지주 |
| 야심 | 무장, 추종자 부양 | 무장 세력, 영주 후보 |
| 관대 | 연회, 선물, 구휼 | 후견인(빚 관계로 추종자를 모음) |
| 독실 | 교단 헌금 | 교단 유력자 |
| 근면 | 개간, 시설 | 큰 자영농, 장인 |
| 만족 | 저장만 늘림 | 안정된 중농 |
| 색욕, 사교 | 혼인 지참금, 구애 선물 | 혼맥 가문 |

같은 잉여에서 성격에 따라 다른 엘리트가 자란다.

### 7-3. 대여와 차입

| 항목 | 규칙 |
|---|---|
| 차입 | 봄에 가을까지 버틸 식량이나 종자가 모자라면 빌린다 |
| 대여자 | 저장분이 2년치 이상인 AI |
| 이자율 | 30% + 담보 부족 위험 + (지역 대여자가 적으면 가산). 상한은 교리와 법이 정한다 |
| 담보 순위 | 필지 → 도구, 가재 → 자기 노동(채무 노역) → 몸(채무 노예, 법이 허용할 때) |
| 미상환 | 1회째는 이자를 원금에 붙여 1년 연장. 2회째는 담보 집행 |

**교리가 바꾸는 결과**: 고리대금 금지 교리 아래 같은 신도끼리는 이자가 0이다. 그래서 대여 대신 **후원**이 된다. 곡식을 주고 빚 수치 +2를 얻는다. 땅은 넘어가지 않는다. 대신 사람이 넘어온다. 받은 사람은 추종, 투표, 병역으로 갚는다.

같은 흉년이 교리에 따라 다른 사회를 만든다. 대여가 허용되면 땅이 쏠리고, 금지되면 후견 관계가 쌓인다.

### 7-4. 소작과 임금 협상

협상은 양쪽의 **바깥 선택지**로 정한다. 바깥 선택지는 그 계약이 깨졌을 때 각자 얻을 수 있는 것이다.

```
소작농 바깥 선택지 O_t = max(무주지 개간 기대 소득, 임금 노동 소득, 이주·도주·도적 기대 소득)
                    도주 쪽은 최소 N × 30%
지주 바깥 선택지   O_l = (다른 소작인을 구할 확률) × 기대 소작료
계약 순수확        N

소작농 몫 = O_t + (N - O_t - O_l) × 소작농 협상력
소작료    = N - 소작농 몫          (10% ~ 관습 상한 50%. 농노제면 70%)
```

- 협상력 기본값은 0.5다. 교역, 언변, 권력차로 보정한다.
- 다른 소작인을 구할 확률은 그 지역에서 땅 없는 성인의 수에 비례한다.

| 상황 | 결과 |
|---|---|
| 무주지가 많다 | O_t가 높다 → 소작료가 낮다. 지주는 사람을 붙잡을 다른 수단을 찾는다(10절) |
| 땅이 꽉 찼다 | O_t는 낮고 땅 없는 사람이 많다 → O_l이 높다 → 소작료가 높다 |
| 농노제 법 | 소작농의 이주 선택지가 사라진다 → O_t가 떨어진다 → 소작료가 오른다 |

임금 협상도 같은 식을 쓴다.

### 7-5. 땅 매매

- 파는 쪽: 굶주림, 빚, 이주.
- 사는 쪽: 잉여가 큰 탐욕, 근면 AI. 위신을 원하는 상인.
- 가격 = 필지의 기대 연 지대 × 15. 지역 매물이 많으면 × 0.5까지 떨어진다.
- 대흉년 뒤 매물이 몰리면 땅값이 떨어지고, 저장해 둔 집이 싸게 산다.

### 7-6. 이주

가구는 매년 지금 셀과 다른 셀의 기대 소득을 비교한다. 이동 비용과 관계 손실(친족, 마을)을 뺀 뒤 더 나으면 옮긴다.

땅 없는 차남들이 무주지가 있는 변경으로 빠져나간다. 변경이 다 차면 이 출구가 닫히고, 안에서 압력이 쌓인다.

## 8. 보호 계약: 영주가 생기는 길

### 8-1. 위협과 선택지

셀마다 **위협 수준**을 계산한다. 주변 도적단과 적대 세력에게 1년 동안 약탈당할 기대 손실(곡식)이다.

위협이 생기면 마을 AI(촌장 + 주요 가구주 투표)는 네 가지를 비교한다.

| 선택 | 비용 | 효과 |
|---|---|---|
| 자경 | 성인 남성 일부의 노동 손실, 장비비 | 인원, 용감 비율, 장비로 정해짐 |
| 보호자 계약 | 수확의 일정 비율 | 보호자의 무력과 평판에 비례 |
| 공물 | 약탈자에게 직접 바침 | 그 약탈자만 막음 |
| 이주 | 땅과 집을 버림 | 위협에서 벗어남 |

마을이 크고, 용감한 사람이 많고, 금속이 싸면 자경이 이긴다. 마을이 작고 흩어져 있고, 금속이 비싸고, 근처에 강한 무장 집단이 있으면 보호자 계약이 이긴다.

### 8-2. 떠도는 도적이 머무는 도적이 되는 조건

도적단 AI는 계절마다 두 값을 비교한다.

```
약탈 기대 = 마을 저장분 × 탈취율 - 손실
           (같은 마을을 거듭 털면 생산이 줄어 값이 계속 떨어진다)
정착 기대 = (수확 × 세율 × 납부율)의 10년 합 - 경쟁 무장 집단을 막는 비용
```

정착 기대가 약탈 기대보다 크고, 반경 3셀 안에 더 강한 무장 집단이 없으면 정착을 고른다.

정착하면 다음 순서로 영주가 된다.
1. 보호비를 요구한다(공포의 이름, 통행세 규율).
2. 분쟁 판결을 맡기 시작한다.
3. 판결로 정통성을 쌓는다.

기존 영주도 매년 같은 계산을 한다. 영주와 도적은 같은 종류의 존재다. 둘을 가르는 것은 시간과 정통성뿐이다.

### 8-3. 판관

보호자가 생기면 마을 분쟁(경계, 빚, 범죄)이 그에게 몰린다. 판결을 집행할 힘이 있는 사람이 그뿐이기 때문이다.

- 판결 1건: 분쟁 가액의 10%를 수수료로 받는다. 공정하면 정통성 +1, 편파적이면 진 쪽 원한이 오르고 목격자의 신뢰가 떨어진다.
- 판결이 쌓이면 그 사람의 판결이 관습이 된다. 재산 인정 강도에 "영주 보증"이 붙는다.
- 땅을 많이 가진 사람일수록 영주의 보증을 원한다. **지주와 영주의 동맹**이 여기서 생긴다.

### 8-4. 보호 계약은 위로 겹친다

작은 영주도 더 강한 이웃에게 위협받는다. 그도 마을과 똑같이 자강, 종속, 공물, 도주 중에서 고른다. 종속을 고르면 봉신이 된다.

같은 함수가 마을 → 영주 → 대영주 → 왕 순서로 겹쳐 쌓이며 피라미드의 윗층을 만든다. 규칙은 하나다.

## 9. 무력의 값이 사회의 모양을 정한다

### 9-1. 전투력

```
개인 전투력 = 장비 계수 × (1 + 전투 기술 / 25)
장비 계수: 맨손 1, 하급 도구 2, 무기 5, 무기 + 갑옷 9
```

| 인물 | 장비 | 기술 | 전투력 |
|---|---|---|---|
| 농민 민병 | 하급 도구 | 5 | 2.4 |
| 무장 농민 | 무기 | 10 | 7 |
| 직업 병사 | 무기 | 35 | 12 |
| 기사 | 무기 + 갑옷 | 60 | 30.6 |

- 기사 1명은 농민 민병 약 13명과 맞먹는다. 그 차이는 장비보다 기술에서 더 많이 나온다.
- 전투 기술은 훈련으로 주당 0.3만 오른다(01_character.md 습득 공식에 계수 0.3). 실전 1회를 살아남으면 +2. 60에 이르려면 농사를 짓지 않고 약 5년을 훈련해야 한다.
- 그러니 기사는 남이 먹여 줘야 생긴다. **무력의 전문화는 잉여에 묶여 있다.**

### 9-2. 장비 가격

무기 30, 갑옷 60으로 올린다(02_economy.md 반영). 한 벌 90은 하급 도구 자영농의 잉여 2년치가 넘는다. 금속 산지가 아니면 지역 가격이 더 오른다.

### 9-3. 금속이 싼 곳과 비싼 곳

| 조건 | 결과 |
|---|---|
| 금속이 비싸다(광맥이 멀고 대장간이 없다) | 소수 기사가 다수 농민을 지배한다. 보호자 계약이 자경을 이긴다. 귀족 사회로 간다 |
| 금속이 싸다(광맥 근처, 장인 조합) | 농민 민병도 무장한다. 자경이 쉬워진다. 자치 도시, 부족 민회 같은 참여 사회로 간다 |

규칙은 같고 지형과 자원 배치만 다르다. 그런데도 다른 사회가 나온다.

### 9-4. 화폐: 봉토로 줄까 녹봉으로 줄까

영주 AI는 무장 인원에게 대가를 주는 방법을 고른다.

| 방법 | 조건 | 장기 결과 |
|---|---|---|
| 숙식(가내 기사) | 영주 창고가 가깝다 | 영주가 직접 통제한다. 창고 크기가 인원을 제한한다 |
| 녹봉(은화) | 은화 수입이 있고 지역 화폐화율 50% 이상 | 통제를 유지하고 해고도 할 수 있다. 권력 집중도가 오른다. 상비군으로 가는 길 |
| 봉토 | 은화가 모자라다 | 기사가 땅을 받아 스스로 먹고산다. 봉토는 세습을 요구하게 되고, 기사가 지역에 뿌리내린다. 권력 집중도가 떨어진다 |

**화폐화율** = 지역 거래 중 은화로 치른 비율. 주조권, 상단 지점, 교역로가 올린다.

은화가 돌지 않는 세계는 봉건으로 기울고, 은화가 도는 세계는 중앙집권으로 기운다. 플레이어가 주조권 법을 넣거나 상단을 키우면 사회 구조가 바뀐다.

### 9-5. 기사 집안이 대를 잇는 이유

- **기사 가구의 연간 비용**: 가족 5명 소비 168 + 장비 교체 + 훈련 기간 = 약 250.
- **봉토 1개의 크기**: 소작 가구 4호의 소작료(69 × 4)로 맞춘다. 경작지 필지 약 16개, 셀의 4분의 1이다.
- **세습되는 이유**:
  - 장비는 물려줄 수 있다.
  - 아버지가 아들을 직접 훈련시킨다(스승 배수).
  - 봉토는 아들이 잇기를 요구하게 된다.

  이 세 가지가 겹쳐서 기사 집안이 대를 잇는다.

## 10. 노동 형태: 땅과 사람의 비율

```
땅 여유 지수 = 지역의 경작 가능 무주지 필지 수 / (지역 성인 노동력 × 2)
```

| 땅 여유 | 자유민의 처지 | 지주가 노동을 붙잡는 방법 |
|---|---|---|
| 높음 (1 이상) | 누구나 개간할 수 있다. 남의 땅을 부칠 이유가 적다 | 소작료가 낮아 수입이 작다. 그래서 노예(포로), 농노제 입법, 채무 예속에 기댄다 |
| 중간 | 자영과 소작이 섞인다 | 소작 계약 |
| 낮음 (0.2 미만) | 땅 없는 사람이 넘친다 | 싼 소작과 머슴으로 충분하다. 노예는 감시비 때문에 오히려 손해다 |

```
노예 수익 = 노예 산출 - 노예 식량 - 감시비(노예 5명당 감시자 1명)
```

이 값을 같은 일을 머슴에게 시킬 때의 임금과 비교한다. 땅이 남을 때는 임금이 비싸서 노예가 이득이다. 땅이 모자랄 때는 임금이 싸서 노예가 손해다.

**역병이 지나가면**: 인구가 줄어 땅 여유 지수가 뛴다. 소작농과 머슴의 협상력이 오른다. 지주들은 농노제나 이주 금지 법을 밀어붙인다. 법이 통과되느냐 마느냐가 그 지역의 다음 100년을 가른다.

## 11. 계층별 발생 경로

### 11-1. 표

| 계층 | 생기는 조건 | 대를 잇는 방식 | 올라가는 길 | 떨어지는 길 |
|---|---|---|---|---|
| 노예 | 포로, 채무 노예, 형벌 | 노예 신분 세습 법이 있을 때만 | 해방, 탈주, 전공, 주인의 총애 | |
| 채무 예속민 | 갚지 못한 빚을 노동으로 갚음 | 빚이 자녀에게 넘어가는 관습 | 상환, 채무 탕감령 | 채무 노예 |
| 머슴, 날품팔이 | 땅도 계약도 없음 | 물려줄 것이 없어 자녀도 같은 처지가 되기 쉽다 | 소작 계약, 병사, 개척 이주, 도적 | 채무 예속 |
| 소작농 | 땅이 없고, 지주가 소작인을 구함 | 계약 갱신, 관습상 승계 | 저축으로 필지 매입, 개척 | 흉년 빚 → 머슴, 예속 |
| 자영농 | 개간, 상속, 매입 | 필지 상속 | 이웃 필지 매입 → 지주 | 분할 상속, 흉년 담보 상실 |
| 장인 | 기술 + 도구 + 시설 + 수요 | 도제로 자식에게 기술, 시설 상속 | 조합장, 상인, 시 의회 | 수요 감소, 조합 축출 |
| 상인 | 은화 + 지역 가격 차 | 상단 지분 상속 | 땅 매입 → 지주. 혼인 → 귀족 | 약탈, 채무국의 몰수 |
| 병사 | 무장 인원 고용, 징집 | 녹봉이면 거의 세습 안 됨 | 전공 → 기사 서임 | 부상, 해고 → 도적 |
| 사제, 학자 | 교단, 학파 + 문해 | 사제 세습 교리면 세습, 독신이면 안 됨 | 교단 서열 | 파문 |
| 도적 | 땅 없는 사람 + 무리 | 두목 세습 규율 | 정착 → 영주(8-2) | 토벌 |
| 지주 | 필지가 가구 노동력보다 많음 | 필지 상속 | 판관, 영주 보증 → 관습 귀족 | 분할 상속, 관리 실패 |
| 기사 | 장비 + 전투 기술 60 + 봉토나 녹봉 | 장비, 훈련, 봉토 세습(9-5) | 봉토 확대 → 영주 | 봉토 박탈, 전사 |
| 영주 | 보호 계약 + 판결 + 징세(8절) | 정통성이 쌓이면 상속이 인정됨 | 종속받기 → 대영주 | 정복당함, 봉기 |
| 대영주, 왕 | 영주들의 종속(8-4) | 상속법, 정통성 | 연맹 맹주 | 반란, 분열 |
| 귀족(법적) | 신분제 입법 시점의 엘리트(12-3) | 법이 세습시킴 | 작위 승급 | 귀천상혼 위반, 반역 |

### 11-2. 교단의 토지 축적

- **사제 독신 교리 아래에서**: 교단 땅은 상속으로 쪼개지지 않는다. 헌금과 유증으로 들어오기만 한다. 수백 년이 지나면 교단이 가장 큰 지주가 된다.
- **충돌**: 영주들은 그 땅을 탐내고, 세속화 입법이나 국가 교단 창시를 노린다.
- **사제 세습 교리 아래에서**: 교단 땅이 사제 가문들 사이에서 쪼개지므로 이 축적이 일어나지 않는다.

교리 하나가 수백 년 뒤의 토지 분포를 바꾼다.

## 12. 위신과 신분

### 12-1. 위신

```
위신 = 생업 위신
     + log2(재산 곡식 환산 + 1) × 5
     + 권력 / 10
     + 가문 명성 / 20
     + 관직 위신
     + 행위 위신
     - 수치
```

| 생업 | 위신 | 생업 | 위신 |
|---|---|---|---|
| 노예 | -40 | 병사 | 10 |
| 채무 예속민 | -20 | 사제, 학자 | 25 |
| 머슴 | -10 | 지주 | 30 |
| 도적 | -10 | 기사 | 40 |
| 소작농 | 0 | 영주 | 60 |
| 자영농 | 10 | 대영주 | 80 |
| 장인, 상인 | 15 | 왕 | 100 |

- 재산은 로그로 넣는다. 아주 부유해도 위신이 끝없이 오르지 않는다.
- **행위 위신**: 연회(참석자 수), 구휼, 전공, 공정한 판결, 순례로 얻는다. 매년 10%씩 줄어서 계속 써야 유지된다.
- **수치**: 공개된 비밀 무게 / 5, 전과, 낙인.
- **쓰임**: 혼인 상대 선택, 첫인상, 명령의 권력차, 생업 선택의 체면, 파벌 지도자 자격.

### 12-2. 실질 계층

생업과 재산으로 매년 다시 계산하는 계층이다. 법이 없어도 AI는 이 계층으로 서로를 대한다. 화면의 신분 피라미드는 이 값을 보여 준다.

### 12-3. 관습 귀족에서 법적 귀족으로

1. **관습 귀족**: 3대 연속 지주 이상 + 가문 명성 300. 주민들이 그 가문을 귀족으로 대우한다(첫인상 +10, 혼인 위신 +20). 아직 법은 없다.
2. **위협**: 부유한 평민(상인, 큰 자영농)의 위신이 관습 귀족에 가까워진다. 그러면 관습 귀족들이 신분제를 선호하게 된다.
3. **입법**: 관습 귀족이 나라 권력 지분의 50% 이상이면 신분제 법안이 자주 나온다.
4. **고정**: 통과되는 순간 그때의 관습 귀족, 기사, 영주 가문이 법적 귀족이 된다. 이후로는 재산을 잃어도 귀족이고, 재산을 모아도 평민이다.
5. **긴장**: 몰락 귀족(위신은 있고 돈이 없다)과 부유 평민(돈은 있고 위신이 없다)이 생긴다. 둘은 혼인으로 서로 원하는 것을 바꾼다. 귀천상혼 금지가 이 거래를 막으면, 부유 평민은 작위 매매나 법 앞의 평등을 원하는 파벌이 된다.

### 12-4. 혼인 시장

```
혼인 효용 = 매력 + 위신 차 보정 + 재산 + 동맹 가치 + 형질 평판
위신 차 보정 = (상대 위신 - 내 위신) × 0.5
```

- 위신 차는 지참금으로 메운다. 위신 1점 차이를 메우려면 곡식 20이 든다.
- 결과적으로 비슷한 계층끼리 혼인하는 것이 기본이 된다. 그 위에 돈으로 위신을 사는 상향혼이 생긴다.
- **혈통의 흐름**: 엘리트끼리 혼인하니 혈통이 상층에 모인다. 동시에 자리를 못 얻은 엘리트 자녀가 아래로 내려가며 혈통을 넓게 퍼뜨린다.

## 13. 이해관계와 입법

### 13-1. 투표

AI 유력자는 법안의 경제 효과를 자기 소득원 기준으로 계산해서 투표한다.

```
투표 점수 = Σ(법안이 내 소득원에 주는 변화) × (1 + 탐욕 보정)
          + 성격 보정 + 제안자 호감 + 소속 파벌 방침
```

| 법 | 지주 | 영주 | 기사 | 소작농 | 자영농 | 장인 | 상인 | 사제 |
|---|---|---|---|---|---|---|---|---|
| 농노제 | ++ | + | + | -- | - | 0 | - | 0 |
| 자유민 | - | - | 0 | ++ | + | + | + | 0 |
| 노예제 | + | + | + | - | - | - | + | 0 |
| 주조권 | 0 | + | - | 0 | 0 | + | ++ | 0 |
| 상비군 | - | ++ | -- | - | - | 0 | 0 | 0 |
| 귀족 특권 | + | + | + | - | - | - | - | 0 |
| 봉토 세습 | 0 | -- | ++ | 0 | 0 | 0 | 0 | 0 |
| 채무 탕감령 | -- | 0 | 0 | ++ | + | 0 | -- | 0 |
| 인클로저 허가 | ++ | + | 0 | -- | - | 0 | 0 | 0 |
| 세속화 | + | ++ | + | 0 | 0 | 0 | 0 | -- |
| 작위 매매 | - | + | - | 0 | 0 | 0 | ++ | 0 |

### 13-2. 제안

- 권력 지분 5% 이상인 유력자는 매년, 자기 투표 점수가 가장 높은 법안을 제안할지 판단한다.
- 경제 조건이 바뀌면 같은 사람의 제안도 바뀐다. 역병 뒤의 지주는 농노제를, 은화가 들어온 뒤의 영주는 상비군을, 교단 땅이 커진 뒤의 영주는 세속화를 꺼낸다.
- 계급 정치는 스크립트로 넣지 않는다. 이해관계에서 나온다.

## 14. 장기 순환

규칙들이 맞물려 아래 순환이 저절로 생기는 것을 목표로 한다. 스크립트 사건으로 넣지 않는다.

| 국면 | 땅 여유 | 소작료, 임금 | 엘리트 | 일어나는 일 |
|---|---|---|---|---|
| 팽창 | 높음 | 소작료 낮음, 임금 높음 | 적음, 자리 충분 | 개간, 인구 증가 |
| 포화 | 낮아짐 | 소작료 오름, 임금 내림 | 늘어남(잘 먹어 아이가 많음) | 땅 쏠림, 빚, 소작 비율 증가 |
| 위기 | 매우 낮음 | 소작농이 생존선 아래 | 자리보다 훨씬 많음 | 파벌, 내전, 봉기. 흉년 한 번이 대기근으로 |
| 붕괴 | 다시 높아짐(인구 감소) | 임금 회복 | 줄어듦(전쟁, 숙청) | 새 팽창 시작 |

```
엘리트 과잉 지수 = 엘리트 성인 남성 수 / 엘리트 자리 수(봉토, 관직, 영지, 교단 고위직)
```

- 1.5를 넘으면 파벌 생성 확률이 2배가 된다.
- 2를 넘으면 내전이 일어날 수 있다.

하렘 군주와 교주 독점 루트는 엘리트 아이를 빠르게 늘려 이 지수를 끌어올린다. 번식 올인의 정치적 대가가 여기서 나온다(11_routes.md).

### 15-5. 계산하면서 새로 넣은 규칙

처음 설계대로 돌리면 30년 안에 전원이 굶어 죽거나, 땅이 찬 뒤 굶주림이 50%까지 갔다. 아래 규칙을 넣어서 맞췄다. 모두 실제 전근대 사회에 있던 장치다.

| 규칙 | 내용 | 빠졌을 때 |
|---|---|---|
| 종자 보존 | 다음 해 종자는 먹지 않는다. 식량 충족률이 70% 아래로 떨어질 때만 손댄다 | 흉년 한 번에 종자를 먹고, 다음 해 경작을 못 해 마을이 전멸 |
| 개간 우선 | 무주지가 있으면 소작보다 자기 땅 개간을 먼저 한다 | 50년 만에 지니 0.57. 개척기인데도 소작농이 생김 |
| 관습 소작료 상한 | 반타작 50%. 농노제 법이 있으면 70% | 땅이 차면 소작료가 70%에 붙고 소작 가족이 굶어 죽음 |
| 도주 선택지 | 소작농의 바깥 선택지는 최소 순수확의 30%(도주, 이주, 도적질) | 소작료가 상한에 붙음 |
| 생전 분재 | 혼인 분가 때 몫을 미리 줌(15_house_tax_inheritance.md 3-3) | 이동률 37%, 대부분 하락 |
| 혼인 전망 | 가난한 남성은 혼인을 미룸(01_character.md 8절) | 굶주림 50%의 대기근 반복 |
| 이주 | 땅 없이 2년 연속 굶은 가구는 매년 30% 확률로 지역을 떠남(7-6) | 무산 30% 이상이 그 자리에서 굶음 |
| 부업 수요 | 잉여 있는 가구는 잉여의 25%를 물건과 일손(의류, 품팔이, 머슴)에 씀. 노동이 남거나 굶는 가구가 받음 | 부자의 잉여가 썩어 없어짐 |
| 출생률 | 부부 연 임신 확률 32%(01_character.md 8절) | 50년 만에 인구 3.5배, 땅이 너무 일찍 참 |

### 15-6. 실패 판정

| 증상 | 조정 |
|---|---|
| 한 가구가 지역 필지 50% 이상 소유 | 흩어지는 고리를 강화 |
| 150년 동안 소작 비율 10% 미만 | 쏠리는 고리를 강화 |
| 세대 간 이동률 5% 미만 또는 50% 이상 | 목표 15~30%로 조정 |

### 15-7. 다음 계산

- C(위협, 보호 계약), E(화폐, 녹봉과 봉토), F(금속, 자경) 시나리오는 무장 집단과 화폐 모델을 시뮬레이터에 넣은 뒤 검증한다.
- 생업 선택(장인, 상인, 병사)은 아직 시뮬레이터에 없다. 지금은 농사, 소작, 채집, 부업만 있다.

## 16. 마을 설계로 넘기는 입력

다음 단계인 마을 형태 설계는 이 문서의 결과를 입력으로 받는다.

| 입력 | 마을 형태에 주는 영향 |
|---|---|
| 위협 수준 | 낮으면 집이 각자 밭 근처로 흩어지고(산촌), 높으면 방어를 위해 모인다(집촌) |
| 필지 소유 분포 | 자영농 마을은 집과 밭이 붙어 있고, 지주 마을은 지주 저택 주변에 소작 가옥이 모인다 |
| 공유지 | 마을 관습이 관리한다. 숲, 풀밭, 사냥터의 위치와 크기 |
| 보호자의 거처 | 방어 지형(언덕), 교역로 근처 |
| 판결 장소, 창고, 사당 | 마을 중심 |
| 장인 위치 | 수요가 모이는 곳(영주 거처, 교차로) |
| 시장 | 화폐화율이 오르면 생긴다 |

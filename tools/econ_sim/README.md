# 경제 시뮬레이터

설계 문서 14_property_and_class.md, 15_house_tax_inheritance.md의 규칙을 연 단위로 돌려서 수치를 검증한다. 게임 코드가 아니다. 표준 라이브러리만 쓴다.

## 실행

시나리오 하나를 연도별로 출력:

```bash
python3 econ_sim.py --scenario A
```

시드 5개 평균으로 여러 시나리오 비교:

```bash
python3 batch.py A 장자 A_tax D 고리금지 상급 장자우대 분재없음
```

## 시나리오

| 이름 | 내용 |
|---|---|
| A | 개척: 평등 30가구, 하급 도구, 세금 없음, 균분 상속 |
| A_tax | A + 영주 세금 10%, 헌물 10% |
| D | A를 150년 돌린 뒤 인구 40% 사망, 30년 더 |
| 장자 | A와 같고 장자 상속 |
| 장자우대 | A와 같고 장자 절반, 나머지 균분 |
| 분재없음 | A와 같고 생전 분재 없음 |
| 고리금지 | A와 같고 고리대금 금지 교리 |
| 상급 | A와 같고 상급 도구(1인 3필지) |

## 한 해의 순서

1. 봄: 자기 땅 경작 배분 → 개간(무주지가 있으면 우선) → 소작 협상과 배분 → 남은 노동은 채집 → 종자
2. 가을: 작황 → 수확 분배(헌물, 세금, 소작료) → 빚 정산과 담보 집행 → 소비, 겨울 대여
3. 잉여: 집 짓기 → 성격별 지출 → 부업 수요 → 땅 매매 → 저장 손실
4. 인구: 사망 → 출생 → 계층 기록 → 혼인(생전 분재) → 이주
